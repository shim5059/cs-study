## 1. 같은 두 개체 사이에도 관계가 여러 개일 수 있다

### 처음 생각 (오답)
"의사는 한 진료과에 소속되고, 진료과마다 의사 한 명이 과장을 맡는다" 같은 시나리오에서, 의사와 진료과 사이에는 마름모를 **하나만** 그릴 수 있다고 생각해서 "과장"을 어떻게 표현할지 막혔다.

### 원리
문장 안의 **동사가 두 개**면 관계도 두 개다.
```
          ┌────── <소속> ──────┐
        N │                    │ 1
     [의사]                   [진료과]
        1 │                    │ 1
          └────── <관리> ──────┘
                 (과장)
```
- 소속: 의사 N : 진료과 1
- 관리(과장): 의사 1 : 진료과 1
- 릴레이션으로 바꾸면 `의사(…, 소속과번호)`, `진료과(…, 과장의사번호)`처럼 외래키가 각각 생긴다

### 깨달음
마름모 하나 = **동사 하나**. 같은 두 개체라도 의미가 다르면 관계를 따로 그린다.

## 2. 2NF와 3NF의 조건을 바꿔 고름

### 처음 생각 (오답)
2NF의 조건으로 "이행적 함수 종속 제거"(3NF 조건)를 골랐다. 부분 함수 종속은 확신 없이 맞혔다.

### 원리
```
기본키 = (학번, 과목번호)

부분 함수 종속 (2NF에서 제거)
  (학번, 과목번호) ──▶ 성적        ← 키 "전체"가 필요 (완전)
   학번 ───────────▶ 이름        ← 키 "일부"로 충분 (부분) ✗

이행적 함수 종속 (3NF에서 제거)
  학번 ──▶ 학과 ──▶ 학과장       ← 키가 아닌 속성(학과)을 거쳐 결정 ✗
```
판단 순서: **키가 여러 속성인가?** → 일부만으로 결정되는 게 있으면 2NF 위반. 그다음 **키 아닌 속성끼리** 결정하면 3NF 위반.

### 깨달음
**도·부·이·결** 순서: 1NF 도메인 원자 → 2NF **부**분 제거 → 3NF **이**행 제거 → BCNF 결정자 = 후보키.

## 3. BCNF 위반을 이행적 종속으로 착각

### 처음 생각 (오답)
"담당 강사가 과목을 결정하는" 릴레이션이 BCNF가 아닌 이유를 **이행적 함수 종속**으로 골랐다.

### 원리
```
특강신청(학번, 특강, 강사)   강사 한 명은 특강 하나만 맡음

 (학번, 특강) ──▶ 강사
  강사 ───────▶ 특강     ← 결정자 "강사"는 후보키가 아님
```
- 이행적 종속은 "**키가 아닌 속성**이 다른 키 아닌 속성을 결정"하는 것 (학번 → 학과 → 학과장)
- 여기서 결정되는 쪽 `특강`은 후보키 (학번, 특강)의 **일부**라서 3NF 조건에는 걸리지 않는다 → 3NF는 만족
- 그래도 결정자(강사)가 후보키가 아니므로 **BCNF 위반**
```
분해 →  강사배정(강사, 특강)    신청(학번, 강사)
```

### 깨달음
BCNF는 함수 종속 화살표의 **왼쪽(결정자)**만 본다: 왼쪽이 모두 후보키인가?

---

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| 두 개체 사이 관계는 하나 | 동사마다 **관계 하나**, 여러 개 가능 |
| 2NF = 이행 제거 | 2NF = **부분** 제거, 3NF = **이행** 제거 |
| BCNF 위반 = 이행적 종속 | BCNF 위반 = **결정자가 후보키 아님** |
