# 5주차 · 요구사항 분석 실습, 이상 현상과 정규화

> 헷갈렸던 부분과 해결 과정: [week05-deep-dive.md](week05-deep-dive.md)

> 교재 8장(요구사항 분석·ERD 실습) + 9장(정규화, BCNF까지) · 시험 강조: **이상 현상 3가지**, **정규형 1NF~BCNF** (4·5정규형은 시험 제외)

## 1. 요구사항 분석 → ERD (수업 실습 흐름)

온라인 쇼핑몰을 예로 업무를 문장으로 나누고, 문장마다 개체·속성·관계를 뽑는다. (아래는 직접 줄여 쓴 예)

| 업무 문장 | 뽑아낸 것 |
|---|---|
| 회원은 아이디·비밀번호·이름·연락처를 입력해 가입한다. 회원은 아이디로 식별한다 | 개체 **회원**, 키 **아이디** |
| 상품은 상품번호·상품명·재고량·단가를 가진다 | 개체 **상품**, 키 **상품번호** |
| 회원은 여러 상품을 주문하고, 한 상품도 여러 회원이 주문한다. 주문수량·주문일자를 기록한다 | 관계 **주문** (N:M), 관계 속성 주문수량·주문일자 |
| 상품 하나는 한 업체가 공급하고, 한 업체는 여러 상품을 공급한다 | 관계 **공급** (업체 1 : 상품 N) |
| 회원은 상품평을 여러 개 쓰고, 상품평 하나는 한 회원이 쓴다 | 개체 **상품평**, 관계 **작성** (회원 1 : 상품평 N) |

- 명사 → 개체/속성, "~로 식별" → 키, 동사 → 관계, "여러/하나" → 카디널리티
- 결과물: 요구사항 명세서 → ERD → (4주차 변환 규칙으로) 릴레이션 스키마

## 2. 이상 현상

관련 없는 속성들이 한 릴레이션에 모여 데이터가 **중복**되면 생기는 문제

직접 만든 예: `수강신청(학번, 이름, 과목번호, 과목명, 성적)`, 기본키 (학번, 과목번호)

```
 학번 | 이름  | 과목번호 | 과목명    | 성적
 s1   | 가람  | c1      | 데이터베이스 | A
 s1   | 가람  | c2      | 자바      | B     ← 가람의 이름이 두 번 (중복)
 s2   | 나래  | c1      | 데이터베이스 | B
```

| 이상 | 뜻 | 위 예에서 |
|---|---|---|
| 삽입 이상 | 새 데이터를 넣으려면 **불필요한 데이터도 함께** 넣어야 함 | 아직 수강 안 한 신입생 s3은 과목번호(기본키 일부)가 NULL이라 삽입 불가 |
| 갱신 이상 | 중복된 투플 중 **일부만 수정**되어 데이터가 **불일치** | 가람의 이름을 첫 행만 고치면 s1의 이름이 두 개 |
| 삭제 이상 | 투플을 지우면 **꼭 필요한 데이터까지 함께 손실** | 나래가 c1 수강을 취소해 행을 지우면 나래의 학생 정보도 사라짐 |

- **정규화**: 이상 현상이 생기지 않도록, **관련 있는 속성들로만** 릴레이션을 구성하도록 **분해**하는 과정

## 3. 함수 종속

- `X → Y`: X 값 하나에 Y 값이 **하나로 정해진다** (X = 결정자, Y = 종속자)
  - 학번 → 이름 (학번을 알면 이름이 하나로 정해짐)

| 종류 | 뜻 | 예 (기본키 (학번, 과목번호)) |
|---|---|---|
| 완전 함수 종속 | 기본키 **전체**에 종속 | (학번, 과목번호) → 성적 |
| 부분 함수 종속 | 기본키의 **일부**만으로 결정됨 | 학번 → 이름 |
| 이행적 함수 종속 | X → Y, Y → Z 이면 X → Z | 학번 → 학과 → 학과장 |

## 4. 정규형 (도·부·이·결)

| 정규형 | 조건 | 제거하는 것 |
|---|---|---|
| 1NF | 모든 속성의 도메인이 **원자 값** | 반복·다중 값 (**도**메인 원자화) |
| 2NF | 1NF + 기본키가 아닌 모든 속성이 기본키에 **완전 함수 종속** | **부**분 함수 종속 |
| 3NF | 2NF + 기본키가 아닌 속성이 기본키에 **이행적 함수 종속되지 않음** | **이**행적 함수 종속 |
| BCNF | 모든 **결**정자가 **후보키** | 후보키가 아닌 결정자 |

## 5. 분해 예 (직접 만든 예)

**2NF로**: 위 `수강신청`의 부분 종속(학번 → 이름, 과목번호 → 과목명) 제거
```
학생(학번, 이름)    과목(과목번호, 과목명)    수강(학번, 과목번호, 성적)
```

**3NF로**: `학생(학번, 학과, 학과장)`에서 학번 → 학과 → 학과장 (이행)
```
학생(학번, 학과)    학과(학과, 학과장)
```

**BCNF로**: `특강신청(학번, 특강, 강사)`, 강사는 특강 하나만 맡음
- 함수 종속: (학번, 특강) → 강사, **강사 → 특강**
- 후보키: (학번, 특강), (학번, 강사) → 강사는 결정자인데 **후보키가 아님** → BCNF 아님
```
강사배정(강사, 특강)    신청(학번, 강사)
```

- (참고, 시험 제외) 4NF: 다치 종속 제거 / 5NF: 후보키를 통하지 않는 조인 종속 제거
