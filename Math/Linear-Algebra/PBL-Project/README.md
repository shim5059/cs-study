# PBL 프로젝트 · 선형변환의 이미지 기하학적 변환 및 기저 변환 사상

선형대수 팀 기반 PBL 프로젝트(9~11주차, 2인 1조) 진행 기록

- 주제: **[주제 10] 선형변환의 이미지 기하학적 변환 및 기저 변환 사상(Mapping)** · 난이도 상 (가산점 +10점) · 관련 주차 11주차
- 팀: 마자신있나 (8조)
- 역할: Member A 수학 모델링 (심수현) / Member B 파이썬 코딩 (이용진)
- 11주차 내용을 미리 써야 해서 필요한 개념을 따로 정리했다 → [concepts.md](concepts.md)

## 문제 정의 (지침서)

이미지 픽셀 좌표계에 선형변환 행렬 $T$와 역변환 $T^{-1}$을 적용해 이미지 회전·왜곡·복원 및 기저 변환 사상을 완성한다.

| 구분 | 내용 |
|---|---|
| 필수 개념 | 선형변환 사상, 기저 변환 행렬 $P_{\mathcal{B}\leftarrow\mathcal{C}}$, 역선형변환, 보간법 기초 |
| 핵심 과제 1 | 순방향 변환과 역방향 픽셀 사상(Inverse Mapping) 수식을 유도해 구멍(Hole) 발생 원인 설명 |
| 핵심 과제 2 | 서로 다른 기저 사이의 변환 행렬 관계 $[T]_{\mathcal{B}} = P^{-1}AP$ 증명 |
| 파이썬 | 역방향 사상 알고리즘을 작성해 변환 및 원본 복원 과정 시각화 |
