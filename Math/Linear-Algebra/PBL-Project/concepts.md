# 주제 10에 필요한 개념 (11주차 미리보기)

> 프로젝트 개요: [README.md](README.md)

> 11주차(선형변환, 기저 변환)를 배우기 전에 프로젝트를 시작해야 해서, 주제 10에 필요한 것만 먼저 정리했다.

## 1. 선형변환 = 좌표를 옮기는 기계

$$T(x) = Ax$$

- 원점은 그대로이고, 모눈종이를 돌리거나 늘리거나 기울여도 **격자선이 곧고 평행하게** 남는다. 회전·확대·전단이 모두 선형변환이다.
- **행렬 만드는 요령**: 기본 벡터 $e_1 = (1,0)$, $e_2 = (0,1)$이 어디로 가는지 구해서 **도착 위치를 열로 세운다.**

```text
90° 회전: e1 = (1,0) → (0,1),  e2 = (0,1) → (-1,0)
       A = [[0, -1],
            [1,  0]]
확인:  A·(2,1) = (-1, 2)  ← (2,1)을 90° 돌린 위치
```

## 2. 역변환 = 되돌리기

옮긴 점을 원래 자리로 돌려놓는 변환이 $T^{-1}$, 행렬로는 $A^{-1}$이다.

| 변환 | $A$ | $A^{-1}$ |
|---|---|---|
| 회전 | $R(\theta)=\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$ | $R(-\theta) = R^T$ (직교행렬) |
| 확대·축소 | $S=\begin{pmatrix}s_x&0\\0&s_y\end{pmatrix}$ | $\begin{pmatrix}1/s_x&0\\0&1/s_y\end{pmatrix}$ |
| 전단 | $H=\begin{pmatrix}1&k\\0&1\end{pmatrix}$ | $\begin{pmatrix}1&-k\\0&1\end{pmatrix}$ |

- 역변환은 $\det A \neq 0$일 때만 존재한다 (9주차 "가역 ⇔ $\det \neq 0$"). $\det A = 0$이면 그림이 선 하나로 눌려서 되돌릴 수 없다.

## 3. 이미지에 적용: 순방향 사상 vs 역방향 사상

이미지 = 정수 좌표 칸(픽셀)마다 색이 들어 있는 격자. 픽셀 좌표를 벡터 $p = (x, y)^T$로 둔다.

| 방식 | 식 | 하는 일 | 결과 |
|---|---|---|---|
| 순방향 (Forward) | $p' = Ap$ | 원본 픽셀마다 새 위치를 계산해서 보냄 | 새 좌표가 소수라 반올림 → **아무도 안 오는 칸(구멍)**, 겹치는 칸이 생김 |
| 역방향 (Inverse) | $p = A^{-1}p'$ | 결과 이미지의 칸마다 원본 위치를 거꾸로 찾아 색을 가져옴 | 모든 칸을 하나씩 채우므로 **구멍이 없음** |

**아파트 이사 비유**: 순방향은 주민마다 새 호수를 계산해서 보내는 방식이라 빈집과 겹친 집이 생긴다. 역방향은 새 아파트의 **집마다** "원래 누가 살았지?"를 거꾸로 찾아 채우는 방식이라 빈집이 없다.

```text
2배 확대 (A = 2I)
순방향: 원본 (0,0)→(0,0), (1,0)→(2,0), (2,0)→(4,0)
        → 결과의 (1,0), (3,0)에는 아무 픽셀도 안 옴 = 구멍
역방향: 결과 (1,0)에 A⁻¹을 곱함 → 원본 (0.5, 0)
        → 정수 좌표가 아니므로 주변 픽셀로 값을 정함 = 보간
```

- 구멍은 행렬 계산의 오류가 아니라, **연속 좌표를 정수 픽셀 좌표로 바꾸는 과정**에서 생긴다.
- 회전 행렬은 원점 기준인데 이미지 원점은 보통 왼쪽 위 모서리라, 이미지 중심 기준으로 돌리려면 "중심으로 옮기기 → 회전 → 다시 옮기기"가 필요하다.

## 4. 보간 (Interpolation)

역방향으로 찾은 원본 위치가 $(0.5,\ 2.3)$처럼 소수일 때 색을 정하는 방법

| 방법 | 방식 | 특징 |
|---|---|---|
| 최근접 이웃 | 가장 가까운 칸의 색을 그대로 사용 | 간단하지만 계단처럼 보임 |
| 양선형 | 주변 4칸의 색을 거리에 따라 섞음 | 더 부드러움 |

## 5. 기저 변환 = 같은 위치를 다른 주소 체계로 부르기

기저는 **좌표를 읽는 자**다. 같은 집을 도로명주소와 지번주소로 부를 수 있듯, 같은 점도 어떤 기저를 쓰느냐에 따라 좌표 숫자가 달라진다.

```text
기저 B = { b1 = (1,1), b2 = (-1,1) }
점 (0,2) = 1·b1 + 1·b2   →  B 좌표로는 (1, 1)
```

- $P = [\,b_1\ b_2\,]$는 **주소 번역기**: $P$는 $\mathcal{B}$ 좌표 → 표준 좌표, $P^{-1}$는 표준 좌표 → $\mathcal{B}$ 좌표
- 확인: $P\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}0\\2\end{pmatrix}$

## 6. $[T]_{\mathcal{B}} = P^{-1}AP$ = 번역 3단계

$A$는 표준 좌표만 알아듣는 기계다. $\mathcal{B}$ 좌표로 들어온 점을 변환하려면 오른쪽부터 차례로 적용한다.

```text
   P            A            P⁻¹
B 좌표 ──▶ 표준 좌표 ──▶ 변환 ──▶ B 좌표
```

세 단계를 합친 $P^{-1}AP$가 **$\mathcal{B}$ 좌표로 표현한 같은 변환** $[T]_{\mathcal{B}}$이다.

**숫자로 확인**: $A = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ (직선 $y=x$에 대한 대칭), $P = \begin{pmatrix}1&-1\\1&1\end{pmatrix}$, $P^{-1} = \tfrac12\begin{pmatrix}1&1\\-1&1\end{pmatrix}$

$$AP = \begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad P^{-1}(AP) = \tfrac12\begin{pmatrix}2&0\\0&-2\end{pmatrix} = \begin{pmatrix}1&0\\0&-1\end{pmatrix}$$

- 표준 좌표로는 복잡하던 대칭이, 대칭축 방향 기저($b_1$은 축 위, $b_2$는 축에 수직)로 보면 "$b_1$ 방향은 그대로, $b_2$ 방향만 뒤집기"로 단순해진다. 이것이 기저를 바꾸는 이유다.
- 일반 증명은 2장 작성 때 정리한다.

```python
import numpy as np

A = np.array([[0, 1], [1, 0]])
P = np.array([[1, -1], [1, 1]])
print(np.linalg.inv(P) @ A @ P)   # [[ 1.  0.] [ 0. -1.]]
print(P @ np.array([1, 1]))       # [0 2]
```
