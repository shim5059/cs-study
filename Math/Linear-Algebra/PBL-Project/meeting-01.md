- 순방향 사상(Forward Mapping)과 역방향 사상(Inverse Mapping)의 차이를 분석하고, 이미지 변환 과정에서 발생하는 구멍(Hole) 현상의 원인과 해결 방법을 논의한다.
- Python의 NumPy, Matplotlib 등을 활용한 이미지 변환 알고리즘 구현 방향을 설정하고, 3주간의 프로젝트 수행 일정 및 팀원별 역할을 분담한다.

## 2. 2인 역할별 수행 내용 및 진행 상황

**Member A (수학 모델링)**
- 이미지의 픽셀 좌표를 벡터로 표현하고, 2×2 변환 행렬을 이용한 회전, 확대·축소, 전단(Shearing) 변환의 수학적 원리를 조사한다.
- 선형변환 $T(x) = Ax$ 및 역변환 $T^{-1}(x) = A^{-1}x$의 관계를 정리하고, 역행렬이 존재하기 위한 조건을 분석한다.
- 순방향 사상 과정에서 출력 좌표의 반올림으로 인해 일부 픽셀이 채워지지 않는 구멍 현상이 발생할 수 있다는 점을 검토한다.
- 새로운 기저에서의 변환 행렬 $[T]_B = P^{-1}AP$를 계산하기 위해 필요한 기저 변환 및 역행렬 개념을 정리한다.

**Member B (파이썬 코딩)**
- Jupyter Notebook을 활용한 Python 실습 환경을 구성하고, NumPy를 이용한 행렬 연산 및 Matplotlib을 활용한 이미지 시각화 방법을 조사한다.
- 이미지를 픽셀 배열로 불러오고, 각 픽셀의 위치를 좌표 벡터로 취급하여 선형변환을 적용하는 프로그램의 구조를 설계한다.
- 순방향 사상과 역방향 사상을 각각 구현하기 위해 필요한 좌표 변환 과정과 반복문 처리 방식을 검토한다.
- 최근접 이웃 보간법 및 양선형 보간법의 기본 개념을 조사하고, 향후 원본 이미지 복원 과정에서 활용할 방법을 검토한다.

## 3. 상호 검증 (Pair Review) 내용 및 피드백

- Member A가 조사한 회전 및 전단 변환 행렬을 Member B의 Python 구현 방식과 비교하여, 수학적 수식이 실제 픽셀 좌표 변환에 어떻게 적용되는지 검토한다.
- 이미지 변환 과정에서 발생하는 구멍 현상이 행렬 자체의 오류가 아니라, 변환된 연속 좌표를 이산적인 픽셀 좌표로 변환하는 과정에서 발생할 수 있음을 논의한다.
- 역방향 사상은 출력 이미지의 각 픽셀에서 원본 이미지의 대응 좌표를 계산한다는 점에서 순방향 사상과 차이가 있음을 확인하고, 보간법을 함께 적용하는 구현 방향을 설정한다.
- 수학적 계산 결과와 Python 시각화 결과를 상호 비교하여 검증하는 방식으로 프로젝트를 진행하기로 계획한다.
