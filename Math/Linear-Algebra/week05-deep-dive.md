## 1. 칸 하나의 소행렬을 행렬식의 답으로 생각함

### 처음 생각 (오답)
여인수 전개에서 한 칸을 골라 그 칸의 3×3 소행렬 det를 구하고, 그 값을 $\det A$라고 생각했다.

### 원리
여인수 전개는 **한 줄 전체**를 쓰는 덧셈이다. 칸 하나는 그 덧셈의 한 항일 뿐이다.

```
det A = a₂₁·C₂₁ + a₂₂·C₂₂ + a₂₃·C₂₃ + a₂₄·C₂₄
         (0)            (3)       (0)       (0)
      = 3 · C₂₂     ← 다른 칸이 0이라서 한 항만 남은 것
```

교안 4×4 예제가 칸 하나만 계산한 것처럼 보였던 이유는 **나머지 칸이 전부 0**이었기 때문이다. 성분 3을 곱하는 것도 빠뜨리면 안 된다 ($C_{22} = -5$이지만 $\det A = -15$).

### 깨달음
여인수 전개 = 줄의 **모든 칸**에 대해 (성분 × 여인수)를 더한다. 0인 칸은 계산을 건너뛸 수 있을 뿐이다.

## 2. 수반행렬의 번호를 안 뒤집음, 부호판을 빠뜨림

### 처음 생각 (오답)
- $\text{adj}(A)$의 $(i, j)$ 칸에 $C_{ij}$를 그대로 넣었다 (전치를 안 함)
- 소행렬 $M_{ij}$만 구하고 부호 $(-1)^{i+j}$를 안 곱했다
- 2×2 공식 $\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$을 구한 뒤 한 번 더 전치했다

### 원리
수반행렬은 **두 단계**다. 순서대로 한 번씩만 한다.

```
① 여인수 행렬 C      : 각 칸 = (-1)^(i+j) × 소행렬      ← 부호판 적용
② 전치             : adj(A) = Cᵀ, 즉 (i, j) 칸 = C_ji   ← 번호 뒤집기

검산: A · adj(A) = det(A) · I  (대각선만 det, 나머지 0)
```

2×2 공식 $\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$은 이미 ①②를 다 한 결과다. 여기서 또 전치하면 $-b$와 $-c$ 자리가 바뀌어 틀린다.

```
A = [[1,2],[3,4]]
  C     = [[ 4, -3], [-2,  1]]
  adj   = Cᵀ = [[ 4, -2], [-3,  1]]   = 공식 [[d, -b], [-c, a]]  ✔
  또 전치 → [[ 4, -3], [-2,  1]]                                    ✘
```

### 깨달음
수반행렬 = 부호판 → 전치, 딱 한 번씩. 다 구한 뒤 $A \cdot \text{adj}(A)$가 $\det(A) I$인지 곱해 보면 실수가 바로 보인다.
