## 1. 외적을 같은 칸끼리 곱해서 계산함 (3번 반복)

### 처음 생각 (오답)
$u \times v$를 $(u_1v_1, u_2v_2, u_3v_3)$처럼 같은 칸끼리 곱했다.

### 원리
같은 칸끼리 곱하는 건 내적의 첫 단계다. 외적은 **다른 칸끼리** 엇갈려 곱한다.

```
u = (1, 3, -1),  v = (-1, 2, 3)

  같은 칸끼리   (1·-1, 3·2, -1·3) = (-1, 6, -3)   ✘ 외적 아님
  외적         가리고 ad - bc     = (11, -2, 5)   ✔

검산: (11,-2,5)·u = 11 - 6 - 5 = 0,  (11,-2,5)·v = -11 - 4 + 15 = 0
```

### 깨달음
`·` 는 결과가 숫자, `×` 는 결과가 벡터. 외적을 구하면 $u$, $v$와 내적해서 둘 다 0인지 30초 검산한다.

## 2. 외적의 가운데($j$) 성분 부호

### 처음 생각 (오답)
$-(1 \cdot 3 - (-1)(-1))$에서 괄호를 다 계산하기 전에 마이너스를 먼저 나눠 붙였다.

### 원리
**괄호 안을 끝까지 계산 → 마지막에 부호를 한 번 뒤집기**

```
① 괄호 안:  1·3 - (-1)(-1) = 3 - 1 = 2
② 뒤집기:   -2
```

### 깨달음
가운데 칸은 "계산 다 하고 마지막에 −". $(-1)(-1) = +1$이라서 $3 - 1$이 된다.

---

## 3. 내적 부호와 각도를 거꾸로 외움

### 처음 생각 (오답)
내적이 양수면 둔각, 음수면 예각이라고 반대로 기억했다.

### 원리
$u \cdot v = \lVert u \rVert \lVert v \rVert \cos\theta$에서 길이는 항상 양수 → 부호 = $\cos\theta$의 부호

```
cos θ > 0  ↔  0° ≤ θ < 90°   (예각, 같은 쪽)   (2,3)·(4,-1) =  5
cos θ = 0  ↔  θ = 90°        (수직)            (2,1)·(-1,2) =  0
cos θ < 0  ↔  90° < θ ≤ 180° (둔각, 반대 쪽)   (2,1)·(-3,1) = -5
```

### 깨달음
바람으로 기억한다. 뒷바람(같은 쪽)은 달리기를 **도와주니까 +**.

---

## 4. $\cos\theta$, 그림자 길이, 그림자 벡터를 섞어 씀

### 처음 생각 (오답)
정사영 벡터를 물었는데 계수 $\frac{u \cdot v}{\lVert v \rVert^2}$까지만 구하고 멈췄다. 그림자 길이와 $\cos\theta$도 헷갈렸다.

### 원리
분모와 마지막 곱셈이 다른 3형제다.

| 이름 | 식 | 결과 | $u = (2,3)$, $v = (4,0)$ |
|---|---|---|---|
| $\cos\theta$ | $\frac{u \cdot v}{\lVert u \rVert\lVert v \rVert}$ | 숫자 | $\frac{8}{4\sqrt{13}}$ |
| 그림자 길이 | $\frac{u \cdot v}{\lVert v \rVert}$ | 숫자 | $2$ |
| 그림자 벡터 | $\frac{u \cdot v}{\lVert v \rVert^2}\,\mathbf{v}$ | 벡터 | $\frac{1}{2}(4, 0) = (2, 0)$ |

### 깨달음
"proj"는 끝에 **$v$를 곱해야** 벡터가 된다. 계수 $\frac{1}{2}$에서 멈추면 숫자일 뿐이다.

## 5. 벡터를 물었는데 숫자(노름)로 답함

### 처음 생각 (오답)
$u_\perp$를 구하라는 문제에 $\sqrt{2}$처럼 길이를 답했다.

### 원리
기호로 구분한다.

```
u⊥        → 벡터  (괄호 안에 칸이 여러 개)
‖u⊥‖      → 숫자  (‖ ‖ 가 붙어 있을 때만 길이)
```

### 깨달음
답을 쓰기 전에 "묻는 게 벡터인가 숫자인가"를 기호로 먼저 확인한다.

---

## 6. 노름을 음수로 씀

### 처음 생각 (오답)
$\lVert v \rVert = 5$일 때 $\lVert -2v \rVert = -10$이라고 썼다. $\lVert cv \rVert$에서 한쪽에만 $c$를 곱하기도 했다.

### 원리
길이는 제곱해서 더한 뒤 루트라서 **절대 음수가 안 된다**.

$$\lVert cv \rVert = \sqrt{(cv_1)^2 + \cdots} = |c|\sqrt{v_1^2 + \cdots} = |c|\,\lVert v \rVert \quad\Rightarrow\quad \lVert -2v \rVert = 2 \times 5 = 10$$

### 깨달음
$\lVert\ \rVert$ 바깥으로 나오는 숫자에는 절댓값이 붙는다.

---

## 7. 기울어진 직선에 정사영할 때 세로로 내림

### 처음 생각 (오답)
$v$가 기울어진 직선일 때도 $u$의 끝에서 $x$축 방향으로 수직선(세로선)을 내렸다. 그림자가 $v$의 끝에서 멈춘다고도 생각했다.

### 원리
그림자는 **$v$ 방향 직선과 직각**으로 내린다. 세로선은 $v$가 $x$축일 때만 맞다. 그림자 길이는 $v$의 길이와 상관없고, $v$보다 길 수도 있다.

```
그림자 끝점 P에서:  (u - P) · v = 0   ← 직선과 직각인지 내적으로 확인
```

### 깨달음
"직각"의 기준은 바닥(직선 $v$)이다. 확인은 $u_\perp \cdot v = 0$.

---

## 8. 반사벡터를 $-u$로 씀

### 처음 생각 (오답)
직선에 대해 반사한 벡터를 $-u$(원점 대칭)라고 썼다.

### 원리
반사는 직선을 접는 선으로 해서 뒤집는 것. 평행 성분은 그대로, 수직 성분만 뒤집힌다.

```
u = u∥ + u⊥
r = u∥ - u⊥ = 2u∥ - u

u = (2,3), 직선 = x축 → u∥ = (2,0) → r = (2,-3)    (−u = (−2,−3) 아님)
y = x 직선이면       (x, y) → (y, x)
```

### 깨달음
원점 대칭($-u$)은 두 성분을 **다** 뒤집는 것이고, 반사는 수직 성분만 뒤집는다. 그래서 $\lVert r \rVert = \lVert u \rVert$ (증명은 [proofs.md](proofs.md)).

## 9. 각도 조건을 $k$의 범위로 그대로 옮김

### 처음 생각 (오답)
"두 벡터가 예각을 이루는 $k$의 범위"에서 $0° < \theta < 90°$를 $k$의 범위처럼 옮겨 적었다.

### 원리
각도 조건은 **내적의 부호 조건**으로 바꾼 뒤 $k$에 대한 부등식을 푼다.

```
예각   ⇔  u · v > 0   → k에 대한 일차부등식을 풀기
둔각   ⇔  u · v < 0
수직   ⇔  u · v = 0   → k에 대한 방정식
```

### 깨달음
각도는 $\theta$에 대한 조건, 답은 $k$에 대한 조건. 둘을 잇는 다리가 내적이다.
