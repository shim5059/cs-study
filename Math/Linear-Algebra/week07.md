## 0. 출발점: 기울기 = 방향

$y = ax + b$의 기울기 $a$는 "$x$가 1 늘 때 $y$가 얼마나 변하나"(변화의 비율)이고, 단위는 ($y$의 단위) ÷ ($x$의 단위)다.

| 상황 | $a$의 뜻 |
|---|---|
| 택시 요금 $y = 1200x + 3600$ (원, km) | 1km당 1,200원, $b$ = 기본요금 |
| 이동 거리 (km, 시간) | 속도 |

"오른쪽 1, 위로 $a$"는 화살표 $(1, a)$로 쓸 수 있다. 3차원은 방향이 3개라 숫자 하나(기울기)로 못 쓰고, **방향벡터**를 쓴다. 기울기가 없는 세로선 $x = 3$도 방향벡터 $(0, 1)$로는 쓸 수 있다.

## 1. 공간의 직선

$$r(t) = r_0 + t\,d \qquad \text{(도착점 = 출발점 + 걸음 수 × 한 걸음)}$$

| 기호 | 뜻 | 교안 예제 1 |
|---|---|---|
| $r_0$ | 출발점 | $(1, 2, -1)$ |
| $d$ | 방향벡터 (한 걸음) | $(2, -1, 3)$ |
| $t$ | 걸음 수 (음수면 뒤로) | 실수 전체 |

| $t$ | $-1$ | $0$ | $1$ | $2$ |
|---|---|---|---|---|
| $r(t)$ | $(-1, 3, -4)$ | $(1, 2, -1)$ | $(3, 1, 2)$ | $(5, 0, 5)$ |

- 성분별: $x = 1 + 2t$, $y = 2 - t$, $z = -1 + 3t$
- 대칭방정식 ($t$ 소거, 방향 성분이 0이 아닐 때): $\dfrac{x - 1}{2} = \dfrac{y - 2}{-1} = \dfrac{z + 1}{3}$
- **두 점 $A$, $B$가 주어지면 방향은 $d = B - A$** — $A(1,4,2)$, $B(3,1,5)$ → $d = (2,-3,3)$
- 같은 직선도 식이 여러 개다 (출발점을 직선 위 다른 점으로, 방향을 상수배로 바꿔도 같은 직선). 검산은 $t$를 넣어 주어진 점들이 나오는지 본다

## 2. 공간의 평면

평면 위의 방향은 무수히 많지만 **평면에 수직인 방향은 하나**다. 그래서 평면 = 한 점 + 법선벡터.

$$n \cdot (r - r_0) = 0 \;\Rightarrow\; a(x - x_0) + b(y - y_0) + c(z - z_0) = 0 \;\Rightarrow\; ax + by + cz + d = 0$$

- 판 위의 걸음 $r - r_0$은 기둥(법선) $n$과 수직 → 내적 0
- **$x, y, z$의 계수가 곧 법선벡터**: $2x - y + 4z - 12 = 0$ → $n = (2, -1, 4)$
- 2차원 직선 $2x - y + 1 = 0$의 계수 $(2, -1)$도 그 직선의 법선이었다

**세 점으로 평면 구하기** (교안 예제 2: $P_1(1,0,1)$, $P_2(2,3,0)$, $P_3(0,2,4)$)

| 단계 | 할 일 | 결과 |
|---|---|---|
| ① | 벡터 2개: $u = P_2 - P_1$, $v = P_3 - P_1$ | $(1, 3, -1)$, $(-1, 2, 3)$ |
| ② | 법선 $n = u \times v$ (둘 다와 수직) | $(11, -2, 5)$ |
| ③ | 한 점 대입 후 전개 | $11x - 2y + 5z = 16$ |
| ④ | 나머지 두 점으로 검산 | $P_2$: $22 - 6 + 0 = 16$, $P_3$: $0 - 4 + 20 = 16$ |

세 점이 한 직선 위에 있으면 외적이 $(0, 0, 0)$이 되어 평면이 정해지지 않는다.

## 3. 코사인 유사도

$$\text{CosSim}(x, y) = \frac{x \cdot y}{\lVert x \rVert \lVert y \rVert} \in [-1, 1]$$

내적은 벡터가 길면 커진다. 길이로 나눠서 **방향(각도)만** 남긴 것이 코사인 유사도다.

| 글 (축구, 야구 단어 수) | A와 비교 |
|---|---|
| A $(2, 1)$, B $(20, 10)$: 같은 주제, B가 10배 김 | $1$ |
| A $(2, 1)$, C $(1, 3)$: 다른 주제 | $\frac{5}{\sqrt5\sqrt{10}} \approx 0.71$ |

교안 예제 3: $x = (1,2,3,4)$, $y = (2,1,5,3)$ → $\frac{31}{\sqrt{30}\sqrt{39}} \approx 0.906$ (교안에는 0.9068로 적혀 있으나 직접 계산하면 0.9063)

## 4. 피어슨 상관계수

**순서: 각 칸에서 자기 평균을 먼저 뺀 다음 → 그 벡터로 코사인 유사도**

$$r = \frac{\tilde{x} \cdot \tilde{y}}{\lVert\tilde{x}\rVert\lVert\tilde{y}\rVert},\qquad \tilde{x} = x - \bar{x}\mathbf{1} = (x_1 - \bar{x}, \ldots, x_n - \bar{x})$$

**코사인 유사도가 속는 경우**: 값이 전부 양수면 화살표가 모두 같은 구석을 가리켜서 흐름과 상관없이 1에 가깝게 나온다.

| 학생 | 점수 | 평균을 뺀 벡터 |
|---|---|---|
| A | $(90, 80, 70)$ ↘ | $(10, 0, -10)$ |
| B | $(60, 70, 80)$ ↗ | $(-10, 0, 10)$ |
| | 코사인 $\approx 0.98$ (거의 같다고 판정) | 피어슨 $= -1$ (정반대) |

교안 예제 3을 다시 보면: 평균 $2.5$, $2.75$ → $\tilde{x} = (-1.5, -0.5, 0.5, 1.5)$, $\tilde{y} = (-0.75, -1.75, 2.25, 0.25)$ → $r = \frac{3.5}{\sqrt5\sqrt{8.75}} \approx 0.529$. 코사인(0.906)보다 정직하게 "약한 양의 상관"을 보여준다.

| 조건·성질 | 예 |
|---|---|
| 두 데이터의 칸은 짝이 맞아야 함 (순서·개수 같게) | 1차 시험끼리, 2차 시험끼리 |
| 값이 전부 같으면 계산 불가 (평균 빼면 영벡터 → 분모 0) | $(5, 5, 5)$ |
| **직선 관계만** 잰다. $r = 0$은 "직선 관계 없음" | $x = (-1,0,1)$, $y = x^2$ → $r = 0$ |
| 모든 칸에 같은 수를 더하거나 양수를 곱해도 $r$은 그대로 | 단위가 다른 데이터끼리 비교 가능 |
| 상관관계 ≠ 인과관계 | 아이스크림 판매량과 물놀이 사고 (둘 다 더위 때문) |

## 5. 최소제곱법과 정규방정식

데이터 점들이 한 직선 위에 있지 않으면 $Ax = b$의 해가 없다 ($b$가 $A$의 열공간 밖). 그래서 오차 $\lVert b - Ax \rVert^2$이 가장 작은 $x$를 찾는다.

- 잔차 $e = b - Ax$가 $A$의 모든 열과 **직교**할 때 거리가 최소 (6주차 정사영과 같은 원리)
- $A^Te = 0 \Rightarrow A^T(b - Ax) = 0 \Rightarrow$ **$A^TAx = A^Tb$** (정규방정식)
- $A$의 열이 일차독립이면 $x = (A^TA)^{-1}A^Tb$ (3주차 왼쪽 역행렬과 같은 모양)

교안 예제 4: 점 $(1,1), (2,3), (3,2), (4,5)$에 $y = \beta_0 + \beta_1 x$ 맞추기

$$A = \begin{pmatrix}1&1\\1&2\\1&3\\1&4\end{pmatrix},\ b = \begin{pmatrix}1\\3\\2\\5\end{pmatrix},\quad
A^TA = \begin{pmatrix}4&10\\10&30\end{pmatrix},\ A^Tb = \begin{pmatrix}11\\33\end{pmatrix}
\Rightarrow \beta = \begin{pmatrix}0\\1.1\end{pmatrix},\ y = 1.1x$$

$\beta_1 = 1.1$은 0주차의 기울기 그대로 "$x$가 1 늘면 $y$는 약 1.1 늘 것"이라는 예측이다.

## 6. 직접 확인

```text
d = B - A = [ 2 -3  3]  r(1) = [3 1 5] == B
틀린 방향(B 좌표)으로 t=1 → [4 5 7] ≠ B
법선 n = [11 -2  5],  평면: 11x + (-2)y + 5z = 16
교안 예제 3: cos = 0.9063, pearson = 0.5292, np.corrcoef = 0.5292
정반대 흐름: cos = 0.9764 (속음), pearson = -1.0000
y = x² (곡선 관계): pearson = 0.0000 ← 직선 관계만 잰다
정규방정식 β = [0.  1.1]  lstsq β = [0.  1.1]
잔차 e = [-0.1  0.8 -1.3  0.6]  Aᵀe = [0. 0.] ← 열공간과 직교
```

## 현업에서는

- 게임·로봇 비전의 레이캐스팅은 광선을 $r_0 + t\,d$로 두고 물체와 처음 만나는 $t$를 구한다. LiDAR로 바닥·벽을 찾는 것은 점들에 평면 $ax + by + cz + d = 0$을 최소제곱으로 맞추는 문제다.
- 검색·추천·AI는 문장이나 사용자를 벡터(임베딩)로 바꾸고 코사인 유사도로 비슷한 것을 찾는다. 사람마다 평점 기준이 다를 때는 평균을 빼는 피어슨 방식이 더 정확하다.
- 선형 회귀(`np.linalg.lstsq`)가 바로 이 정규방정식이다. 실제로는 수치 안정성 때문에 $(A^TA)^{-1}$을 직접 구하지 않고 QR 분해 등을 쓴다.
