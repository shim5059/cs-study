## 1. 미분계수와 도함수를 구분하기

### 처음 생각
미분계수는 $f'(2)$ 같은 것, 도함수는 $f'(x)$인 것 같은데 확실하지 않았다.

### 원리
맞게 생각한 것. 차이는 **결과가 숫자냐 함수냐**다.

| | 미분계수 $f'(a)$ | 도함수 $f'(x)$ |
|---|---|---|
| 결과 | 숫자 (한 점의 접선 기울기) | 함수 (아무 점이나 넣으면 기울기를 내줌) |
| 관계 | 도함수에 $x = a$를 대입한 값 | 미분계수를 모든 $x$에 대해 모은 것 |

### 깨달음
"구하시오"가 숫자를 원하는지(미분계수) 식을 원하는지(도함수) 먼저 본다.

## 2. 분수·루트를 지수로 바꾸는 것에서 막힘

### 처음 생각 (오답)
$x^{-\frac43}$이 무엇인지 몰라서 보기 두 개 사이에서 골랐다.

### 원리
지수 법칙 두 개만 있으면 된다.

```text
x^(-n)    = 1 / x^n          (음수 지수 = 역수)
x^(n/m)   = m제곱근(x^n)      (분수 지수 = 거듭제곱근)
```

그래서 $x^{-\frac43} = \dfrac{1}{\sqrt[3]{x^4}}$. 반대로 미분할 때는 $\dfrac{1}{\sqrt[3]{x}} = x^{-\frac13}$로 바꾸고 $(x^n)' = nx^{n-1}$을 쓴다. 지수를 1 뺄 때 $-\frac13 - 1 = -\frac43$처럼 **음수에서 빼는 계산**에서 실수하기 쉽다.

### 깨달음
분수·루트가 보이면 먼저 $x^{\square}$ 꼴로 바꾸고, 지수 계산을 한 줄 따로 적는다.

## 3. 몫의 미분에서 분자의 부호

### 처음 생각 (오답)
몫의 미분을 계산했는데 보기에 답이 없었다. 분자를 $f'g + fg'$처럼 **더하기**로 계산했다.

### 원리

$$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$$

- 곱의 미분 $f'g + fg'$와 모양이 같아서 섞인다. 몫은 **빼기**, 그리고 **분자 $f$를 먼저 미분**
- 외우는 법: "위 미분·아래 그대로 **빼기** 위 그대로·아래 미분, 나누기 아래 제곱"
- 검산: $f = 1$을 넣으면 $\left(\frac1g\right)' = \frac{0 - g'}{g^2} = -\frac{g'}{g^2}$. 이 결과가 나와야 맞다

### 깨달음
몫의 미분은 곱의 미분과 부호가 다르다. 보기에 답이 없으면 분자 부호부터 의심한다.

## 4. 삼각함수 극한 (아직 연습 필요)

### 처음 생각
$\lim_{x \to 0} \dfrac{\sin 7x}{5x}$를 어떻게 풀지 몰랐다.

### 원리
기본 극한 $\lim_{\square \to 0} \dfrac{\sin \square}{\square} = 1$은 **위아래 $\square$가 같아야** 쓸 수 있다. 분모를 $7x$로 맞추고 남는 상수를 밖으로 뺀다.

$$\frac{\sin 7x}{5x} = \frac{\sin 7x}{7x} \cdot \frac{7x}{5x} \to 1 \cdot \frac75 = \frac75$$

### 깨달음
$\sin$ 안의 것과 분모를 똑같이 만드는 것이 첫 단계다.

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| 미분계수·도함수가 헷갈림 | 미분계수 = 숫자, 도함수 = 함수 |
| $x^{-\frac43}$을 못 읽음 | 음수 지수 = 역수, 분수 지수 = 거듭제곱근 |
| 몫의 미분 분자를 더함 | $f'g - fg'$, 검산은 $f = 1$ 넣기 |
| $\frac{\sin 7x}{5x}$를 못 풂 | $\sin$ 안과 분모를 같게 만든 뒤 상수 정리 |
