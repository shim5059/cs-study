## 1. 극한 · 연속 · 미분가능

| 개념 | 정의 | 판정 |
|---|---|---|
| 극한 | $x \to a$일 때 $f(x)$가 다가가는 값 | 좌극한 = 우극한일 때만 존재 |
| 연속 | $\lim_{x \to a} f(x) = f(a)$ | ① $f(a)$ 존재 ② 극한 존재 ③ 둘이 같음 |
| 미분가능 | $f'(a) = \lim_{h \to 0} \dfrac{f(a+h) - f(a)}{h}$가 존재 | 왼쪽 기울기 = 오른쪽 기울기 |

- **미분가능 ⇒ 연속**, 역은 성립 안 함. $|x|$는 $x = 0$에서 연속이지만 기울기가 왼쪽 $-1$, 오른쪽 $+1$이라 미분 불가능(뾰족점)
- **미분계수** $f'(a)$ = 한 점에서의 순간 변화율 = 접선의 기울기 → **숫자**
- **도함수** $f'(x)$ = 모든 점의 미분계수를 내주는 **함수**. 미분계수는 도함수에 $x = a$를 대입한 것
- 평균 변화율 $\dfrac{f(b) - f(a)}{b - a}$ (할선 기울기)에서 간격을 0으로 보낸 것이 미분계수

## 2. 기본 미분법

| 규칙 | 식 |
|---|---|
| 상수 | $(c)' = 0$ |
| 거듭제곱 | $(x^n)' = nx^{n-1}$ ($n$이 음수·분수여도 성립) |
| 상수배 | $(cf)' = cf'$ |
| 합·차 | $(f \pm g)' = f' \pm g'$ |
| 곱 | $(fg)' = f'g + fg'$ |
| 몫 | $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$ (분자 순서·**마이너스** 주의) |
| 역수 | $\left(\dfrac{1}{g}\right)' = -\dfrac{g'}{g^2}$ (몫의 미분에서 $f = 1$) |
| 지수 | $(e^x)' = e^x$, $(a^x)' = a^x \ln a$ |
| 로그 | $(\ln x)' = \dfrac{1}{x}$ |
| 세 개의 곱 | $(fgh)' = f'gh + fg'h + fgh'$ |

- 거듭제곱 공식을 쓰기 전에 **지수 꼴로 바꾸기**: $\dfrac{1}{x^n} = x^{-n}$, $\sqrt[m]{x^n} = x^{n/m}$
- 합·차와 상수배 규칙 = 미분이 **선형** 연산이라는 뜻: $(af + bg)' = af' + bg'$. 선형대수의 선형변환 조건(덧셈·스칼라곱 보존)과 같은 성질이다

## 3. 삼각함수의 미분

| $f$ | $f'$ |
|---|---|
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\cot x$ | $-\csc^2 x$ |
| $\sec x$ | $\sec x \tan x$ |
| $\csc x$ | $-\csc x \cot x$ |

- **co-** 가 붙은 것($\cos$, $\cot$, $\csc$)의 도함수는 마이너스
- $\tan x = \dfrac{\sin x}{\cos x}$에 몫의 미분을 쓰면 $\dfrac{\cos^2 x + \sin^2 x}{\cos^2 x} = \sec^2 x$

**$(\sin x)' = \cos x$의 근거가 되는 두 극한**

$$\lim_{h \to 0} \frac{\sin h}{h} = 1, \qquad \lim_{h \to 0} \frac{\cos h - 1}{h} = 0$$

| 줄 | 식 | 근거 |
|---|---|---|
| 1 | $\dfrac{\sin(x+h) - \sin x}{h}$ | 도함수 정의 |
| 2 | $\dfrac{\sin x\cos h + \cos x\sin h - \sin x}{h}$ | 덧셈정리 |
| 3 | $\sin x \cdot \dfrac{\cos h - 1}{h} + \cos x \cdot \dfrac{\sin h}{h}$ | $\sin x$, $\cos x$끼리 묶기 |
| 4 | $\to \sin x \cdot 0 + \cos x \cdot 1 = \cos x$ | 위의 두 극한 |

**삼각함수 극한 응용**: $\dfrac{\sin(\square)}{\square} \to 1$ 꼴을 만든다.

$$\lim_{x \to 0} \frac{\sin 7x}{5x} = \lim_{x \to 0} \frac{\sin 7x}{7x} \cdot \frac{7}{5} = \frac{7}{5}, \qquad \lim_{x \to 0} \frac{\tan x}{x} = \lim_{x \to 0} \frac{\sin x}{x} \cdot \frac{1}{\cos x} = 1$$

## 4. 시그모이드와 활성화 함수

$$\sigma(x) = \frac{1}{1 + e^{-x}}, \qquad \sigma'(x) = \sigma(x)\bigl(1 - \sigma(x)\bigr)$$

| 줄 | 식 | 근거 |
|---|---|---|
| 1 | $\sigma' = -\dfrac{(1 + e^{-x})'}{(1 + e^{-x})^2}$ | 역수 미분 |
| 2 | $= \dfrac{e^{-x}}{(1 + e^{-x})^2}$ | $(e^{-x})' = -e^{-x}$ (연쇄법칙) |
| 3 | $= \dfrac{1}{1 + e^{-x}} \cdot \dfrac{e^{-x}}{1 + e^{-x}}$ | 분리 |
| 4 | $= \sigma(1 - \sigma)$ | $\dfrac{e^{-x}}{1 + e^{-x}} = 1 - \dfrac{1}{1 + e^{-x}}$ |

- 출력이 $(0, 1)$ 사이 → 확률처럼 해석. $\sigma(0) = 0.5$, $\sigma'$의 최댓값은 $x = 0$에서 $0.25$
- 계단함수(미분하면 0이라 학습 불가) → 시그모이드(매끄러워 미분 가능) → ReLU $\max(0, x)$ (깊은 신경망에서 기울기가 작아지는 문제를 줄임)
- 도함수를 자기 자신 $\sigma$로 쓸 수 있어서, 역전파 때 이미 계산한 출력값을 재사용한다

## 5. 고계도함수

- $f''$ = 도함수를 한 번 더 미분. 위치 $s(t)$ → 속도 $v = s'$ → 가속도 $a = v' = s''$
  - 수업 실습: $s = t^3 + t$ → $v = 3t^2 + 1$ → $a = 6t$
- 반복 패턴 찾기

| $f$ | $n$계 도함수 | 패턴 |
|---|---|---|
| $e^x$ | $e^x$ | 그대로 |
| $\cos x$ | $\cos x \to -\sin x \to -\cos x \to \sin x \to \cos x$ | 주기 4 → $n$을 4로 나눈 나머지로 판단 ($27 = 4 \cdot 6 + 3$ → $\sin x$) |
| $\ln x$ | $\dfrac{(-1)^{n+1}(n-1)!}{x^n}$ | 부호 번갈아, 계승 증가 |

## 6. 연쇄법칙 (합성함수의 미분)

$$\bigl(f(g(x))\bigr)' = f'(g(x)) \cdot g'(x) \qquad \frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$$

- **겉미분 × 속미분**: 바깥 함수를 미분하고(속은 그대로 둠), 속 함수의 도함수를 곱한다
- 뉴턴 표기 $f'(g(x))g'(x)$와 라이프니츠 표기 $\frac{dz}{dy}\frac{dy}{dx}$는 같은 내용. 라이프니츠 표기는 $dy$가 약분되는 것처럼 보여서 외우기 쉽다

| 함수 | 겉 / 속 | 도함수 |
|---|---|---|
| $(x^3 + 1)^{100}$ | $u^{100}$ / $x^3 + 1$ | $300x^2(x^3 + 1)^{99}$ |
| $\cos^2 x$ | $u^2$ / $\cos x$ | $-2\cos x\sin x = -\sin 2x$ |
| $e^{x^2 + 1}$ | $e^u$ / $x^2 + 1$ | $2x\,e^{x^2 + 1}$ |
| $\cos 2x$ | $\cos u$ / $2x$ | $-2\sin 2x$ |
| $\ln 100x$ | $\ln u$ / $100x$ | $\dfrac{100}{100x} = \dfrac{1}{x}$ |

- 신경망의 **역전파**가 층마다 연쇄법칙을 곱해 나가는 것이다

## 7. 실습 코드 (SymPy)

| 함수 | 하는 일 |
|---|---|
| `sym.symbols('x')` | 기호 변수 만들기 |
| `sym.diff(f, x)` / `sym.diff(f, x, 2)` | 도함수 / 2계 도함수 |
| `sym.limit(expr, h, 0)` | 극한 (예: `((1+h)**3 - 1)/h` → 3) |
| `expr.subs(t, 3)` | 값 대입 |
| `sym.lambdify(x, f, 'numpy')` | 기호식을 NumPy 함수로 바꿔 그래프 그리기 |

- 수업 실습: $e^x \cot x$와 그 도함수를 `lambdify`로 바꿔 함께 그림. $\cot x$가 $x = k\pi$에서 발산하므로 `plt.ylim(-50, 50)`으로 범위를 잘라야 보인다

## 선형대수와 연결

- 미분은 선형 연산이다: 다항식 공간 $P_n$에서 미분은 $P_n \to P_{n-1}$ 선형변환이고, 기저 $\{1, x, x^2, \ldots\}$에 대한 행렬로 쓸 수 있다
- 10주차 편도함수는 여기의 모든 규칙을 "다른 변수는 상수로 두고" 그대로 쓴다
