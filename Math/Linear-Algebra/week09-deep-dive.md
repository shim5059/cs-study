## 1. "정확히 $n$차 다항식"이 덧셈에 닫혀 있다고 생각함

### 처음 생각 (오답)
- 덧셈에 닫혀 있지 않은 것을 고르는 문제에서 "차수가 정확히 2인 다항식 전체" 대신 $\mathbb{R}^3$을 골랐다. 2차원 이상이라 닫혀 있지 않을 것 같다고 생각했다
- 다음 문제에서는 반대로 "차수가 정확히 1인 다항식 전체"가 덧셈에 닫혀 있다고 골랐다

### 원리
닫힘은 공간의 크기(차원)와 상관없다. $\mathbb{R}^3$은 무엇을 더해도 숫자 3개짜리 벡터라 방 안에 남는다. "정확히 $n$차"는 최고차항끼리 지워지는 짝을 고르면 바로 깨진다.

```text
x² + (-x² + 1) = 1   → 차수 0 → "정확히 2차" 방 밖
x  + (-x  + 1) = 1   → 차수 0 → "정확히 1차" 방 밖
```

영벡터(다항식 0)도 차수가 2가 아니라서 방 안에 없다. 그래서 벡터공간 $P_n$은 "$n$차 **이하**"로 정의한다. 차수 ≠ 차원: 차수는 다항식의 가장 높은 거듭제곱, 차원은 공간의 방향 개수다.

### 깨달음
"정확히 몇 차"가 보이면 최고차항이 서로 지워지는 두 개를 골라 더해본다.

## 2. 닫힘을 "공간 전체를 만족해야 한다" 또는 "부분적으로 닫힘"으로 이해함

### 처음 생각 (오답)
- "닫혀 있다는 건 전체를 만족해야 한다는 거지? 그러면 $\mathbb{R}^2$ 전체만 닫혀 있다"고 생각했다
- $y = x + 1$에서 $(1,2)$와 $(1,2)$를 골라 보고 "둘 다 직선 위에 있으니 닫혀 있다, 대신 부분적으로 닫혀 있다"고 판단했다. 같은 이유로 $y = -3x$, $x = 2$, $x + 2y = 5$도 닫혀 있을 수 있다고 봤다

### 원리
- "전체"는 방이 공간 전체여야 한다는 뜻이 아니라, **방 안의 모든 짝에 대해** 성립해야 한다는 뜻이다. 작은 방(원점을 지나는 직선)도 닫혀 있을 수 있다
- "부분적으로 닫힘"은 없다. 한 짝이라도 밖으로 나가면 그냥 "안 닫힘"이다
- 고른 두 점이 방 안에 있는지는 입장 확인일 뿐이다. 닫힘은 **더한 결과**를 봐야 한다

```text
y = x + 1 위의 (1,2) + (1,2) = (2,4)  → x+1 = 3인데 y = 4 → 탈락
문자로: (a, a+1) + (b, b+1) = (a+b, a+b+2) → 어떤 a, b든 항상 1씩 어긋남
```

숫자 몇 개로는 "모든 짝"을 확인할 수 없으므로 문자로 두 점을 잡아 확인한다.

### 깨달음
닫힘 = 방 안의 어떤 두 개를 더해도, 결과가 다시 방 안에 있다. 확인은 문자로, 반례는 하나면 충분하다.

## 3. 영벡터 포함만 보고 부분공간이라고 판정함

### 처음 생각 (오답)
- 제1사분면($x \ge 0,\ y \ge 0$)이 영벡터를 포함하니 부분공간이라고 했다
- $x \ge 0$인 $(x, y, z)$ 전체도 "위배되는 것이 없다"며 부분공간이라고 했다
- $y = x^2$도 원점을 지나니 부분공간이라고 골랐다

### 원리
영벡터 포함(①)은 입구 검사일 뿐이다. ②덧셈 닫힘과 ③스칼라곱 닫힘까지 통과해야 부분공간이다. ③의 스칼라 $c$는 실수 전체라서 음수와 분수가 들어온다.

```text
제1사분면 : (-1)·(1,1) = (-1,-1)     → 제3사분면으로 나감
x ≥ 0     : (-1)·(1,0,0) = (-1,0,0)  → x = -1, 방 밖
정수 격자 : 0.5·(1,1) = (0.5,0.5)    → 정수 아님
```

곡선은 원점을 지나도 깨진다.

```text
y = x² : (1,1) + (1,1) = (2,2) → 2² = 4인데 y = 2 → 탈락
```

### 깨달음
원점 확인 후 반드시 ②③까지 한다. 부등호가 보이면 −1배, 정수 조건이면 0.5배, 제곱이 보이면 두 점을 더해 본다.

## 4. 부분공간은 공간 전체여야 한다고 생각함

### 처음 생각 (오답)
- $\mathbb{R}^2$의 부분공간이 아닌 것을 고르는 문제에서 "$\mathbb{R}^2$ 전체"를 골랐다
- $2x - y + z = 0$은 "전체 공간이 아니라서" 부분공간이 아니라고 했다

### 원리
부분공간은 건물 안의 방이다. 크기는 상관없고 3조건만 통과하면 된다. $V$ 자기 자신도 부분공간이다 (부분집합이 자기 자신을 포함하는 것과 같다). $\mathbb{R}^3$의 부분공간은 원점 하나, 원점을 지나는 직선, 원점을 지나는 평면, $\mathbb{R}^3$ 전체의 4종류다.

$2x - y + z = 0$을 문자로 확인하면 통과한다.

```text
덧셈    : 2(a1+b1) - (a2+b2) + (a3+b3) = (2a1-a2+a3) + (2b1-b2+b3) = 0 + 0
스칼라곱 : 2(c·a1) - (c·a2) + (c·a3)  = c · 0
```

### 깨달음
"일차식 = 0" 꼴(원점을 지나는 직선·평면)은 공간 전체가 아니어도 부분공간이다.

## 5. "포함"과 "닫힘"을 섞어서 씀

### 처음 생각 (오답)
원점 테스트를 "$(0,0)$에 닫혀 있는지 확인하는 것"이라고 표현했다.

### 원리

| 말 | 뜻 | 예 |
|---|---|---|
| 포함 (원소) | 그 점이 집합 안에 있다 | $0 \in W$ |
| 포함 (집합) | 그 집합이 다른 집합 안에 있다 | $W \subseteq V$ |
| 닫힘 | 계산한 결과가 집합 안에 남는다 | $u + v \in W$ |

부분공간 = $V$에 포함된 집합 중, 영벡터를 포함하고, 덧셈·스칼라곱에 닫힌 것.

### 깨달음
원점 테스트는 "$(0,0)$이 그 집합 안에 들어 있는지", 즉 영벡터 포함 확인이다.

## 6. 행렬의 행벡터를 영공간의 원소로 고름

### 처음 생각 (오답)
$A = \begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$의 영공간에 들어 있는 벡터를 고르는 문제에서, 행렬 첫째 행 그대로인 $(1,2,3)$을 골랐다.

### 원리
영공간은 $x_1 + 2x_2 + 3x_3 = 0$을 만족하는 벡터다. 보기를 식에 넣어보면 끝난다.

```text
(1,2,3)  → 1 + 4 + 9 = 14  ✘
(-2,1,0) → -2 + 2 + 0 = 0  ✔
```

$x_1 + 2x_2 + 3x_3 = 0$은 $(1,2,3) \cdot x = 0$, 즉 행벡터와의 내적이 0이라는 뜻이다. 그래서 영공간은 행벡터에 수직인 벡터들이다. 7주차 평면 방정식과 연결하면, 계수 $(1,2,3)$은 평면의 법선벡터(수직으로 꽂힌 막대)이고 영공간은 그 막대에 수직인 바닥(평면)이다.

### 깨달음
행벡터는 영공간의 법선(막대), 영공간은 그 막대에 수직인 평면. 영공간 원소인지는 식에 넣어 0이 나오는지로 확인한다.

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| $\mathbb{R}^3$은 2차원 이상이라 안 닫힘 | 닫힘은 차원과 무관. 결과가 집합 안에 남는지만 본다 |
| 정확히 $n$차 다항식은 닫힘 | 최고차항이 지워지는 짝 $x^2 + (-x^2 + 1) = 1$ → 안 닫힘. 그래서 $P_n$은 "이하" |
| 닫힘 = 공간 전체여야 함 / 부분적으로 닫힘 | 방 안의 모든 짝에 대해 성립해야 함. 한 짝이라도 나가면 안 닫힘 |
| 두 점이 직선 위에 있으면 닫힘 | 그건 입장 확인. 더한 결과가 직선 위에 있는지 봐야 함 |
| 영벡터만 있으면 부분공간 | ①은 입구 검사. ②③까지 통과해야 함 |
| 스칼라는 양수만 | $c$는 실수 전체 → 음수·분수 넣어보기 |
| 원점을 지나는 곡선도 부분공간 | 곡선($y = x^2$)은 ②③에서 깨짐. 곧은 "일차식 = 0"만 통과 |
| 부분공간은 전체 공간이어야 함 | 원점 하나, 직선, 평면, 전체 모두 가능. 자기 자신도 부분공간 |
| $(0,0)$에 닫혀 있는지 확인 | $(0,0)$이 집합 안에 포함되는지 확인 |
| 행벡터 $(1,2,3)$이 영공간 원소 | 행벡터는 영공간의 법선. 영공간은 행과 수직인 벡터들 |
