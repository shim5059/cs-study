## 1. 벡터공간 (Vector Space)

덧셈과 스칼라곱이 정의되어 있고 아래 10가지 공리를 만족하는 집합 $V$. 그 원소를 벡터라고 부른다.

- 벡터는 화살표만이 아니다. 다항식, 행렬, 함수도 더하고 몇 배 할 수 있으면 벡터다
- 한 번 증명한 정리(일차독립, 기저, 차원 등)를 다항식·행렬 공간에 그대로 다시 쓸 수 있다는 것이 핵심 이점이다

| 덧셈 공리 | 스칼라곱 공리 |
|---|---|
| ① $u + v \in V$ (덧셈 닫힘) | ⑥ $cu \in V$ (스칼라곱 닫힘) |
| ② $u + v = v + u$ (교환) | ⑦ $c(u + v) = cu + cv$ (분배 1) |
| ③ $(u + v) + w = u + (v + w)$ (결합) | ⑧ $(c + k)u = cu + ku$ (분배 2) |
| ④ 영벡터 $0$ 존재: $u + 0 = u$ | ⑨ $c(ku) = (ck)u$ |
| ⑤ 역원 $-u$ 존재: $u + (-u) = 0$ | ⑩ $1u = u$ |

- 나머지 8개는 당연한 계산 규칙이고, 실제로 따지는 것은 **닫힘 2개**다
- 닫힘 = 방 안의 원소끼리 더하거나 몇 배 해도 결과가 방 밖으로 튀어나가지 않는다

**대표적인 벡터공간**

| 공간 | 원소 |
|---|---|
| $\mathbb{R}^n$ | 실수 $n$개짜리 순서쌍 |
| $M_{m \times n}(\mathbb{R})$ | 모든 $m \times n$ 실수 행렬 |
| $P_n(x)$ | 차수가 $n$ **이하**인 다항식 ("정확히 $n$차"가 아님) |
| $C[a, b]$ | 구간 $[a, b]$에서 연속인 함수 |

## 2. 닫힘 판정 레시피

```text
① 입장 조건을 한 줄로 적는다                  예) "첫 성분이 0"
② 조건을 만족하는 원소 두 개를 문자로 잡는다   (a 꼴), (b 꼴)
③ 더한 결과(또는 c배 한 결과)가 입장 조건을 여전히 만족하는지 본다
   → 한 짝이라도 밖으로 나가면 "안 닫힘" (반례 하나로 끝, "부분적으로 닫힘"은 없음)
```

| 집합 | 더하기 | 결과 |
|---|---|---|
| $y = -3x$ | $(a, -3a) + (b, -3b) = (a + b,\ -3(a + b))$ | 닫힘 |
| $y = x + 1$ | $(a, a + 1) + (b, b + 1) = (a + b,\ a + b + 2)$ | 항상 1씩 어긋남 → 안 닫힘 |
| 정확히 2차 다항식 | $x^2 + (-x^2 + 1) = 1$ | 차수 0 → 안 닫힘 |

오른쪽이 0인 일차식 조건은 살아남고 ($0 + 0 = 0$, $c \cdot 0 = 0$), 0이 아닌 값이면 깨진다 ($3 + 3 = 6$).

## 3. 부분공간 (Subspace)

벡터공간 $V$ 안의 부분집합 $W \subseteq V$가 그 자체로 벡터공간이 되면 부분공간이다. 계산 규칙은 큰 공간에서 물려받으므로 3조건만 확인한다.

| 조건 | 식 | 의미 |
|---|---|---|
| ① 영벡터 포함 | $0 \in W$ | 원점이 방 안에 있다 (입구 검사) |
| ② 덧셈 닫힘 | $u, v \in W \Rightarrow u + v \in W$ | 더해도 안 샌다 |
| ③ 스칼라곱 닫힘 | $c \in \mathbb{R},\ u \in W \Rightarrow cu \in W$ | 늘리고, 줄이고, 뒤집어도(음수), 쪼개도(분수) 안 샌다 |

- ③에서 $c = 0$을 넣으면 $0 \cdot u = 0$이므로, 영벡터가 없으면 바로 탈락이다
- 포함과 닫힘은 다른 말이다: 포함은 "그 점이 방 안에 있나", 닫힘은 "계산한 결과가 방 안에 남나"
- 부분공간은 공간 전체일 필요가 없다. 원점 하나도, $V$ 자기 자신도 부분공간이다

**판정 카드**

```text
1. 원점 넣기             → 안 되면 바로 탈락              (x+y=2, x+y+z=1, z=3)
2. 부등호(≥, >)가 있으면 → -1배 넣기 → 대부분 탈락       (제1사분면, x≥0)
3. 정수 조건이면         → 0.5배 넣기 → 탈락             (정수 격자)
4. 제곱·절댓값이 있으면  → 원점이 있어도 ②③에서 탈락     (y=x²)
5. "일차식 = 0" 꼴이면   → 통과 (원점을 지나는 직선·평면)
```

**$\mathbb{R}^3$의 부분공간은 딱 4종류**

- 원점 하나 $\{0\}$
- 원점을 지나는 직선 $\{t\,d\}$
- 원점을 지나는 평면 $ax + by + cz = 0$ (7주차 평면 방정식 $ax + by + cz + d = 0$에서 $d = 0$)
- $\mathbb{R}^3$ 전체

## 4. 증명: 2×2 대칭행렬 집합은 부분공간 (교안 추가 예제 2-1)

$W = \{A \in M_{2 \times 2} \mid A^T = A\}$

| 줄 | 식 | 이유 |
|---|---|---|
| 1 | $O^T = O$ | 영행렬은 성분이 전부 0이라 전치해도 같음 |
| 2 | 따라서 $O \in W$ | ① 통과 |
| 3 | $A, B \in W$, 즉 $A^T = A,\ B^T = B$라 하자 | 가정 (문자로 = 모든 짝) |
| 4 | $(A + B)^T = A^T + B^T$ | 전치의 성질: 합의 전치 = 전치의 합 |
| 5 | $= A + B$ | 3줄 가정 대입 |
| 6 | 따라서 $A + B \in W$ | ② 통과 |
| 7 | $c \in \mathbb{R},\ A \in W$라 하자 | 가정 |
| 8 | $(cA)^T = cA^T$ | 전치의 성질: 스칼라는 밖으로 |
| 9 | $= cA$ | 7줄 가정 대입 |
| 10 | 따라서 $cA \in W$ | ③ 통과 |
| 11 | ∴ $W$는 $M_{2 \times 2}$의 부분공간 | ①②③ 모두 성립 |

- 핵심: 전치가 덧셈과 스칼라곱을 그대로 통과하니까 대칭 조건이 깨지지 않는다
- 같은 방법으로 교대대칭행렬($K^T = -K$)도 부분공간: $(cK)^T = cK^T = c(-K) = -(cK)$
- 구조는 고등학교의 "짝수 + 짝수 = 짝수" 증명($2m + 2n = 2(m + n)$)과 같다

## 5. 영공간 $N(A)$와 열공간 $C(A)$

행렬 $A$ = 입력 $x$를 넣으면 출력 $Ax$가 나오는 기계

| 구분 | 영공간 $N(A)$ | 열공간 $C(A)$ |
|---|---|---|
| 정의 | $\{x \mid Ax = 0\}$ | $\{Ax \mid x\text{는 아무거나}\} = \text{span}(a_1, \ldots, a_n)$ |
| 묻는 것 | 어떤 입력이 0을 내나 (기계의 사각지대) | 어떤 출력을 만들 수 있나 |
| 사는 곳 | 입력 공간 $\mathbb{R}^n$ | 출력 공간 $\mathbb{R}^m$ |
| 뼈대 벡터 | $Ax = 0$을 풀어 얻은 해벡터 | $A$의 열벡터 |

- $Ax$를 열로 보기: $\begin{pmatrix}1&2\\3&4\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix} = x_1\begin{pmatrix}1\\3\end{pmatrix} + x_2\begin{pmatrix}2\\4\end{pmatrix}$ → 행렬 곱은 열들을 $x$만큼 섞은 것 (물감 섞기)
- **가장 중요한 한 줄: $Ax = b$에 해가 있다 $\iff b \in C(A)$**
- 영공간은 행벡터와 수직: $x_1 + 2x_2 + 3x_3 = 0$은 $(1,2,3) \cdot x = 0$이므로, 행벡터 $(1,2,3)$은 평면의 법선이고 영공간(평면) 위에 없다

**교안 예제 2-2A**: $A = \begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$

| 줄 | 식 | 이유 |
|---|---|---|
| 1 | $x_1 + 2x_2 + 3x_3 = 0$ | 둘째 행이 첫째 행의 2배라 식이 하나만 남음 ($R_2 - 2R_1$) |
| 2 | $x_2 = s,\ x_3 = t$ | 피벗이 없는 열 = 자유변수 |
| 3 | $x_1 = -2s - 3t$ | 1줄을 $x_1$에 대해 정리 |
| 4 | $x = s\begin{pmatrix}-2\\1\\0\end{pmatrix} + t\begin{pmatrix}-3\\0\\1\end{pmatrix}$ | $s$항, $t$항 분리 |
| 5 | $N(A) = \text{span}\{(-2,1,0), (-3,0,1)\}$ | $\mathbb{R}^3$에서 원점을 지나는 평면 |

**교안 예제 2-2B**: $A = \begin{pmatrix}1&2\\2&4\\3&6\end{pmatrix}$

- 둘째 열이 첫째 열의 2배 → $C(A) = \text{span}\{(1,2,3)\}$ = 원점을 지나는 직선
- $b_1 = (3,6,9) = 3(1,2,3)$ → $b_1 \in C(A)$, 해 있음
- $b_2 = (1,0,0)$ → $(1,2,3)$을 몇 배 해도 안 나옴 → 해 없음

## 6. 선형결합과 생성 (span)

- 선형결합: $c_1v_1 + c_2v_2 + \cdots + c_kv_k$
- span: 가능한 모든 선형결합의 집합. 항상 원점을 지나므로 항상 부분공간이다

| $\mathbb{R}^3$에서 | span의 모양 |
|---|---|
| 벡터 1개 | 원점을 지나는 직선 |
| 평행하지 않은 2개 | 원점을 지나는 평면 |
| 평행한 2개 | 하나가 쓸모없어서 여전히 직선 |

**교안 예제 3** (교안 답이 틀린 문제, 수업에서 정정됨): $b = (1,5,9)$가 $v_1 = (1,2,3)$, $v_2 = (0,1,3)$의 선형결합인가?

```text
1번째 성분: c1 = 1
2번째 성분: 2·1 + c2 = 5  → c2 = 3
3번째 성분 검산: 3·1 + 3·3 = 12 ≠ 9   → 선형결합으로 표현 불가 (교안의 "가능"은 오류)
```

성분 2개로 $c$를 구한 뒤 나머지 성분으로 **반드시 검산**한다.

## 7. 일차독립과 일차종속

$$c_1v_1 + c_2v_2 + \cdots + c_kv_k = 0$$

- 해가 $c_1 = \cdots = c_k = 0$뿐 (자명해) → **일차독립** (모두가 꼭 필요함)
- 0이 아닌 해(비자명해)가 있음 → **일차종속** (어떤 벡터가 다른 벡터들로 만들어짐)
- 예: $(1,2), (3,6)$ → $3(1,2) - 1(3,6) = 0$ → 종속

**판별 정리** ($n$개 벡터를 열로 세운 정방행렬 $A$, 전부 동치 — 3주차 가역행렬 동치 정리와 같은 목록)

```text
일차독립 ⇔ Ax = 0의 해가 x = 0뿐 ⇔ RREF = I ⇔ A 가역 ⇔ det A ≠ 0 ⇔ rank A = n
```

이유: $c_1v_1 + c_2v_2 + c_3v_3 = A\,c$이므로, $\det A \neq 0$이면 $c = A^{-1}0 = 0$뿐이다.

**교안 예제 4**: $v_1 = (1,2,3)$, $v_2 = (0,1,4)$, $v_3 = (2,5,10)$

$$\det\begin{pmatrix}1&0&2\\2&1&5\\3&4&10\end{pmatrix} = 1(10 - 20) - 0 + 2(8 - 3) = 0 \Rightarrow \text{종속}\quad(v_3 = 2v_1 + v_2)$$

**교안 예제 4-1 (다항식)**: 계수 벡터 (상수, $x$, $x^2$)로 바꾸면 $\mathbb{R}^3$ 문제가 된다.

| 다항식 | 계수 벡터 |
|---|---|
| $p_1 = 1 + x$ | $(1, 1, 0)$ |
| $p_2 = 1 - x^2$ | $(1, 0, -1)$ |
| $p_3 = x + x^2$ | $(0, 1, 1)$ |

$$\det\begin{pmatrix}1&1&0\\1&0&1\\0&-1&1\end{pmatrix} = 1(0 + 1) - 1(1 - 0) + 0 = 0 \Rightarrow \text{종속}\quad(p_1 - p_2 - p_3 = 0)$$

## 8. 기저와 차원 미리보기 (10주차 연결)

- 기저 = span(공간 전체를 만든다) + 일차독립(쓸모없는 게 없다) → 공간의 최소 뼈대
- 차원 = 기저 벡터의 개수, rank = 열공간의 차원

| 공간 | 기저 | 차원 |
|---|---|---|
| 예제 2-2A의 $N(A)$ | $(-2,1,0),\ (-3,0,1)$ | 2 (평면) |
| 예제 2-2B의 $C(A)$ | $(1,2,3)$ | 1 (직선) |
| $\mathbb{R}^3$ | $(1,0,0), (0,1,0), (0,0,1)$ | 3 |

$$\text{rank}(A) + \dim N(A) = n\ (\text{열 개수})\qquad \text{예제 2-2A: } 1 + 2 = 3$$

"반응하는 입력 방향(rank) + 반응 안 하는 방향(영공간) = 입력 방향 전부". 10주차의 차원 정리(Rank-Nullity)로 이어진다.

## 9. 파이썬 확인 (NumPy)

```python
import numpy as np

# 예제 4: 세 벡터를 열로 세운 행렬
A = np.array([[1, 0, 2],
              [2, 1, 5],
              [3, 4, 10]])
print(np.linalg.det(A))           # 0.0 → 종속
print(np.linalg.matrix_rank(A))   # 2 < 3 → 종속

# 예제 2-2A: 영공간 뼈대 벡터를 넣으면 0이 나오는지 확인
B = np.array([[1, 2, 3],
              [2, 4, 6]])
print(B @ np.array([-2, 1, 0]))   # [0 0]
print(B @ np.array([-3, 0, 1]))   # [0 0]
print(np.linalg.matrix_rank(B))   # 1 → dim N(B) = 3 - 1 = 2
```

- 교안은 SymPy `Matrix(A).rref()`, `Matrix(A).nullspace()`와 SciPy `scipy.linalg.null_space()`도 소개한다
- det는 부동소수점 계산이라 정확히 0 대신 아주 작은 수가 나올 수 있다. 종속 판정은 `matrix_rank`가 더 안전하다
