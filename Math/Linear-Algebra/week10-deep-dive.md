## 1. 이변수함수도 평면에 그릴 수 있다고 생각함

### 처음 생각 (오답)
$(x, y)$를 넣으면 값이 하나만 나오니까, 일변수처럼 평면에 그릴 수 있을 것 같았다.

### 원리
그래프의 점 하나에 필요한 숫자 개수를 센다.

```text
일변수 : (x, f(x))       → 숫자 2개 → 축 2개 = 평면
이변수 : (x, y, f(x,y))  → 숫자 3개 → 축 3개 = 공간
```

입력 $(x, y)$가 가로·세로축을 이미 차지해서 출력을 놓을 세 번째 축(높이)이 필요하다. 평면에 나타내려면 높이를 선으로 바꾼 **등위곡선**을 쓴다.

### 깨달음
변수가 하나 늘면 그래프 차원이 하나 오른다. 평면에 그린 건 그래프가 아니라 등위곡선이다.

---

## 2. 서로 다른 입력의 출력이 같으면 함수가 아니라고 생각함

### 처음 생각 (오답)
$\sqrt{9 - x^2 - y^2}$에서 $x$가 3일 때와 $y$가 3일 때 값이 둘 다 0인데, 함수는 출력이 하나여야 하지 않나?

### 원리
함수의 두 조건은 **입력 → 출력** 한 방향만 본다.

1. 모든 입력에 출력이 있다
2. 입력 하나가 출력 두 개로 가면 안 된다: $f(x) = y_1,\ f(x) = y_2 \Rightarrow y_1 = y_2$

$(3, 0) \to 0$, $(0, 3) \to 0$은 서로 다른 입력이 각각 출력 하나씩 가진 것이라 조건 2와 무관하다. 또 이변수의 입력은 항상 짝 $(x, y)$이므로 "$x$가 3일 때"만으로는 입력이 정해지지 않는다.

### 깨달음
출력이 같은 입력이 여러 개인 건 괜찮다. 그 점들을 이은 것이 바로 등위곡선이다.

## 3. 대입해서 분모가 0이 되면 극한이 없다고 생각함

### 처음 생각 (오답)
$\dfrac{xy^2}{x^2 + y^4}$에서 직선 $y = mx$를 따라가면 원점에서 분모가 0이니까 "존재하지 않음" 아닌가?

### 원리
극한은 0을 **대입**하는 게 아니라 0에 **다가가는** 것이다.

| 줄 | 식 | 근거 |
|---|---|---|
| 1 | $\dfrac{m^2x^3}{x^2 + m^4x^4}$ | 그대로 넣으면 $\frac00$ → 부정형, 아직 모름 |
| 2 | $\dfrac{m^2x}{1 + m^4x^2}$ | 분자·분모를 $x^2$으로 약분 |
| 3 | $\to \dfrac{0}{1} = 0$ | 분모가 1로 감 |

약분해도 되는 이유: ε-δ 정의의 $0 < |x - a|$, 즉 $x \ne 0$. 0에 한없이 가까이 가지만 도착하지 않는다.

```text
분모만 → 0              : 발산 / 극한 없음
분자·분모 둘 다 → 0 (0/0): 약분·정리해서 다시 본다
```

### 깨달음
$\frac00$은 답이 아니라 "정리하라"는 신호. 고등학교 $\lim_{x\to1}\frac{x^2-1}{x-1} = 2$와 같은 원리다.

## 4. 직선 경로에서 전부 0이면 극한이 0이라고 생각함

### 처음 생각 (오답)
$y$축, $y = x$, $y = mx$ 모두 0이 나오니까 극한은 0이다.

### 원리
이변수는 다가가는 길이 무수히 많고, **모든** 길에서 같아야 극한이 있다. 직선은 그중 일부일 뿐이다. 분모 $x^2 + y^4$의 두 항이 같은 크기가 되는 곡선 $x = y^2$을 고르면

$$\frac{y^2 \cdot y^2}{y^4 + y^4} = \frac12 \ne 0$$

### 깨달음
경로 판정은 "다른 값이 나오는 길 하나"를 찾는 것. 직선이 다 같으면 분모 차수를 맞추는 곡선을 시도한다.

## 5. 이변수 극한에서 무엇이 평면이 되는지 헷갈림

### 처음 생각
판서의 ε-δ 그림은 수직선 위 구간인데, 이변수에서는 전부 평면이 되는 건지 헷갈렸다.

### 원리
**입력 쪽만 평면, 출력 쪽은 그대로 수직선.**

```text
δ 쪽 (입력) : 구간 0 < |x - a| < δ   → 원판 0 < √((x-a)² + (y-b)²) < δ  (중심 제외)
ε 쪽 (출력) : |f - L| < ε            → 그대로
```

입력 범위가 원판이라 다가가는 방향이 왼쪽·오른쪽 2개가 아니라 무한히 많아진다. 그래서 "두 길에서 값이 다르면 극한 없음"이 가능하다.

### 깨달음
이변수 극한 = 입력은 원판 안에서 사방으로 다가가고, 출력은 숫자 하나가 $L$ 근처에 있는지 본다.

## 6. 입체 그래프와 등위곡선이 연결되지 않음

### 처음 생각
$x, y, z$축 그림과 등위곡선이 어떻게 이어지는지 안 잡혔다.

### 원리
순서대로 쌓는다.

```text
① 바닥 깔기     : 정의역(반지름 3 원판)을 xy평면에
② 뼈대 잡기     : x=0, y=0으로 자르면 위쪽 반원 두 개 (절편으로 직선 그리듯)
③ 덮기          : 뼈대 전체를 덮으면 반구
④ 등위곡선      : 반구를 같은 간격의 높이 k에서 수평으로 자르고 위에서 내려다봄
                  √(9-x²-y²) = k → x² + y² = 9 - k² (원)
```

$k$가 0 → 3으로 올라갈수록 원이 작아지다가 꼭대기에서 점 하나가 된다. 원 사이 간격이 좁은 곳(반구 가장자리)이 가파르다.

### 깨달음
입체 그래프 = 바닥 점마다 높이 세우기, 등위곡선 = 그 입체를 같은 간격으로 수평으로 자른 자국.

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| 이변수함수도 평면에 그릴 수 있음 | 점 하나에 숫자 3개 → 공간. 평면에 그린 건 등위곡선 |
| 다른 입력의 출력이 같으면 함수 아님 | 입력 하나 → 출력 하나만 보면 됨 |
| "x가 3일 때"를 입력으로 봄 | 이변수 입력은 항상 짝 $(x, y)$ |
| 분모가 0이 되면 극한 없음 | $\frac00$은 부정형 → 약분 후 다시 봄 |
| 직선 경로가 다 0이면 극한 0 | 곡선 경로($x = y^2$)에서 다른 값 → 극한 없음 |
| 이변수 극한은 전부 평면 | 입력($\delta$)만 원판, 출력($\varepsilon$)은 수직선 그대로 |
