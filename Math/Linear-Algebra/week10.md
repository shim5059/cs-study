## 1. 함수의 정의 다시 보기

$D \subseteq \mathbb{R}$일 때 $f: D \to \mathbb{R}$ = "정의역이 $D$, 공역이 $\mathbb{R}$인 함수" ($\mathbb{R}$ = real number, $f$ = function)

| 용어 | 뜻 |
|---|---|
| 정의역 $D$ | 입력 $x$가 들어 있는 집합. $x$ = **독립변수** |
| 공역 $\mathbb{R}$ | 출력이 들어갈 수 있는 집합 |
| 상(이미지) $f(x)$ | $x$에 대응된 값. $y = f(x)$, $y$ = **종속변수** |
| 치역 $f(D)$ | $\{f(x) \mid x \in D\}$, 실제로 나온 출력 전부 |
| 그래프 $G(f)$ | $\{(x, f(x)) \mid x \in D\}$, 순서쌍(점)의 집합 |

**함수가 되기 위한 두 조건**

1. $D$의 **모든** $x$에 대해 짝이 되는 $y$가 반드시 있다: $(x, y) \in f$, 즉 $y = f(x)$
2. 한 점이 두 점으로 가면 안 된다: $(x, y_1) \in f$이고 $(x, y_2) \in f$이면 $y_1 = y_2$

- $y = f(x)$는 함수(대응)에 중점을 둔 표기, $(x, y) \in f$는 **관계(relation)** 관점의 표기. 함수는 관계의 특별한 경우다
- 조건은 "입력 → 출력 하나" 한 방향만 본다. 서로 다른 입력이 같은 출력으로 가는 것은 괜찮다
- 차원 세기: 1차원 → 1차원 함수의 그래프는 2차원 평면에 그려진다

## 2. 다변수함수 · 이변수함수

**다변수 = 정의역 안의 독립변수가 여러 개.** 변수 2개면 이변수, 3개면 삼변수, 2개 이상을 통틀어 다변수함수라고 한다. 출력은 여전히 실수 하나.

**곱집합 (Cartesian product)**

$$D_1 \times D_2 = \{(x, y) \mid x \in D_1,\ y \in D_2\}$$

- $D_1 = [a, b]$, $D_2 = [c, d]$이면 $D_1 \times D_2$는 $xy$평면의 **직사각형 영역**
- 끝점 포함(폐구간)이면 경계를 실선, 빠지면 점선으로 그린다

**이변수함수** $f: D \to \mathbb{R}$, $D \subseteq \mathbb{R}^2$ ($\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$)

| | 일변수 | 이변수 |
|---|---|---|
| 정의역 | $D \subseteq \mathbb{R}$ (수직선) | $D \subseteq \mathbb{R}^2$ (평면) |
| 입력 | 점 $x$ | 점 $(x, y)$ |
| 출력 | $f(x)$ | $z = f(x, y)$ (실수 하나) |
| 치역 | $\{f(x) \mid x \in D\}$ | $\{f(x, y) \mid (x, y) \in D\} \subseteq \mathbb{R}$ |
| 그래프 | $\{(x, f(x))\}$ → 평면의 곡선 (2차원) | $\{(x, y, f(x, y))\}$ → 공간의 곡면 (3차원) |

함수가 되는 조건(1절의 두 조건)은 그대로이고, 입력이 수직선의 점에서 평면의 점으로 바뀐 것뿐이다. 변수가 하나 늘 때마다 그래프의 차원이 하나 올라간다.

## 3. 수업 예제: $f(x, y) = \sqrt{9 - x^2 - y^2}$

**① 정의역**: 루트 안이 $0$ 이상이어야 한다.

$$9 - x^2 - y^2 \ge 0 \iff x^2 + y^2 \le 3^2$$

→ 중심이 원점, 반지름 3인 원의 내부 + 경계(등호라 원도 포함)

**② 대응**: 원점 → 3, $(3, 0)$·$(-3, 0)$·$(0, 3)$ → 0 (경계 위의 점은 전부 0)

**③ 그래프 그리기**: 직선을 절편으로 그리듯, 좌표평면으로 잘라 뼈대를 먼저 잡는다.

| 자르는 면 | 식 | 모양 |
|---|---|---|
| $x = 0$ ($yz$평면) | $y^2 + z^2 = 9$, $z \ge 0$ | 위쪽 반원 |
| $y = 0$ ($xz$평면) | $x^2 + z^2 = 9$, $z \ge 0$ | 위쪽 반원 |

두 반원을 원점에서 겹친 뒤 90° 돌려 세우고 전체를 덮으면 → **위쪽 반구** (공을 반으로 잘라 바닥에 엎어 놓은 모양)

- $z = \sqrt{\ \cdot\ } \ge 0$이라 $xy$평면 아래쪽은 없다
- 최댓값: $(0, 0)$에서 $3$

**④ 치역**: $[0, 3]$

## 4. 등위곡선 (Level Curve)

곡면을 **일정한 간격의 높이**로 수평하게 자르고, 위에서 빛을 비춰 $xy$평면에 생긴 그림자 = 등위곡선 (지도의 등고선)

$$f(x, y) = k \quad (k\text{는 상수})$$

- 반구는 모두 원으로 나온다: $x^2 + y^2 = 9 - k^2$. 바닥($k=0$)이 가장 큰 원이고 올라갈수록 안쪽에 작은 원
- **간격이 좁으면 경사가 가파르고, 넓으면 완만하다**
- 같은 등위곡선 위의 점들은 출력이 모두 같다

## 5. 일변수 극한 복습: 좌극한 · 우극한 · 연속

- 도함수 $f'(x) = \lim_{h \to 0} \dfrac{f(x+h) - f(x)}{h}$도 극한으로 정의된다 → 이변수에서 도함수를 정의하려고 이변수 극한을 먼저 한다
- 미분 불가능한 점이 있을 수 있어서 $f'$의 정의역 $\subseteq$ $f$의 정의역

실수에는 **순서(크다·작다)**가 있어서, $a$에 다가가는 방법은 두 가지뿐이다.

| | 기호 | 다가가는 쪽 |
|---|---|---|
| 우극한 | $\lim_{x \to a^+} f(x)$ | $a$보다 큰 쪽(오른쪽) |
| 좌극한 | $\lim_{x \to a^-} f(x)$ | $a$보다 작은 쪽(왼쪽) |

| 경우 | 극한 | 연속 |
|---|---|---|
| 좌극한 ≠ 우극한 | 없음 | × |
| 좌극한 = 우극한 = $L$, $f(a)$ 없음 또는 $f(a) \ne L$ | 있음 ($L$) | × |
| 좌극한 = 우극한 = $f(a)$ | 있음 | ○ (그래프가 안 끊김) |

- 극한은 $a$에서의 함숫값이 있든 없든 상관없다
- **연속** = 극한값과 함숫값이 같다: $\lim_{x \to a} f(x) = f(a)$

## 6. ε-δ 정의

$$\lim_{x \to a} f(x) = L \iff \forall \varepsilon > 0,\ \exists \delta > 0 : 0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon$$

**입력 쪽** $0 < |x - a| < \delta$ 풀기

| 단계 | 식 | 근거 |
|---|---|---|
| 1 | $-\delta < x - a < \delta$ | 절댓값 풀기 |
| 2 | $a - \delta < x < a + \delta$ | 양변에 $a$ 더하기 |
| 3 | $x \ne a$ | $0 < \lvert x - a \rvert$ (절댓값은 원래 $\ge 0$인데 $>0$을 붙임) |
| 4 | $x \in (a - \delta, a) \cup (a, a + \delta)$ | 가운데 $a$만 뺀 열린구간 두 조각 |

**출력 쪽** $|f(x) - L| < \varepsilon \iff f(x) \in (L - \varepsilon, L + \varepsilon)$. 여기는 $0 <$이 없어서 $f(x) = L$이어도 된다.

- 순서가 중요: **$\varepsilon$을 먼저**(임의로, 아주 작게) 고르고 → 그때마다 맞는 $\delta$가 **존재**하면 수렴
- $\varepsilon$은 출력 구간의 양 끝, $\delta$는 $a$를 중심으로 한 입력 구간의 양 끝을 정한다
- 특정 $\varepsilon$ 하나가 아니라 **모든** $\varepsilon$에 대해 성립해야 한다

**한쪽 극한의 ε-δ**: 입력 구간만 바뀌고 나머지는 같다.

| | 입력 조건 |
|---|---|
| 우극한 | $x \in (a, a + \delta)$ |
| 좌극한 | $x \in (a - \delta, a)$ |
| 극한 | 둘 중 아무 데나 ($x \in (a-\delta, a) \cup (a, a+\delta)$) |

**연속의 ε-δ**: $0 <$ 조건이 빠지고 $L$ 자리에 $f(a)$가 들어간다.

## 7. 이변수함수의 극한

$$\lim_{(x, y) \to (a, b)} f(x, y) = L$$

$\forall \varepsilon > 0,\ \exists \delta > 0$:

$$0 < \sqrt{(x - a)^2 + (y - b)^2} < \delta \Rightarrow |f(x, y) - L| < \varepsilon$$

| | 일변수 | 이변수 |
|---|---|---|
| 입력 범위 | 구간 $(a-\delta, a+\delta)$, $a$ 제외 | 중심 $(a, b)$, 반지름 $\delta$인 **열린 원판**(open disk), 중심 제외 |
| 출력 범위 | $(L - \varepsilon, L + \varepsilon)$ | 그대로 |
| 다가가는 방법 | 왼쪽·오른쪽 **2가지** | 직선, 포물선 … **무수히 많음** |

- $\sqrt{(x-a)^2 + (y-b)^2}$ = 평면에서 두 점 사이의 거리 (일변수의 $|x - a|$ 역할)
- 원판 대신 정사각형으로 잡아도 결과는 같다
- 멀리서부터 볼 필요 없이 $(a, b)$ 가까이의 점들만 본다
- **모든 경로**에서 같은 값이 나와야 극한이 있다 → 존재를 보이기는 어렵고, **경로 두 개에서 값이 다르면 극한이 없다**고 보이는 문제가 주로 나온다
- 연속: $\lim_{(x,y) \to (a,b)} f(x, y) = f(a, b)$

**수업 예제 1 — 극한이 없음**: $f(x, y) = \dfrac{xy^2}{x^2 + y^4}$, 정의역 $\mathbb{R}^2 - \{(0,0)\}$

| 경로 | 대입 | 극한 |
|---|---|---|
| $y$축 ($x = 0$) | $\dfrac{0}{y^4} = 0$ | $0$ |
| 직선 $y = x$ | $\dfrac{x^3}{x^2 + x^4} = \dfrac{x}{1 + x^2}$ | $0$ |
| 포물선 $x = y^2$ | $\dfrac{y^4}{y^4 + y^4} = \dfrac12$ | $\dfrac12$ |

→ 경로에 따라 값이 다르므로 극한 없음. 직선 경로를 아무리 많이 해도 같은 값이면 판정이 안 되고, 분모의 두 항($x^2$, $y^4$) 차수를 맞추는 곡선을 골라야 다른 값이 나온다.

> 녹음에서는 포물선 경로 값이 "1"로 들리지만 $\frac{y^4}{2y^4} = \frac12$이 맞다. 결론(극한 없음)은 같다.

**수업 예제 2 — 연속이면 대입**: 극한의 성질(합·차·상수배·곱)은 일변수와 같다. 다항함수는 연속이므로 극한값 = 함숫값.

$$\lim_{(x, y) \to (1, 2)} (x^2y^3 - x^3y^2 + 3x + 2y) = 8 - 4 + 3 + 4 = 11$$

## 8. 편도함수 (Partial Derivative)

하나만 변수로 보고 **나머지는 상수로 고정**해서 미분한다.

$$f_x(x, y) = \lim_{h \to 0} \frac{f(x + h, y) - f(x, y)}{h}, \qquad f_y(x, y) = \lim_{k \to 0} \frac{f(x, y + k) - f(x, y)}{k}$$

- $f_x$: $y$는 그대로, $x$만 $x \to x+h$로 움직임. 움직인 양 $h$로 나누고 $h \to 0$
- 계산은 지난주까지 배운 도함수 공식(곱·몫·합성함수 미분법)을 그대로 쓰면 된다

**표기**

| $x$에 대한 편도함수 | $y$에 대한 편도함수 |
|---|---|
| $f_x$, $z_x$, $\dfrac{\partial f}{\partial x}$, $\dfrac{\partial z}{\partial x}$, $D_1 f$ | $f_y$, $z_y$, $\dfrac{\partial f}{\partial y}$, $\dfrac{\partial z}{\partial y}$, $D_2 f$ |

- $\partial$ = 편미분 기호(라운드 디). 일변수의 $\dfrac{d}{dx}$ 자리에 쓴다
- $D_1, D_2$ = 첫 번째·두 번째 변수로 미분 (가끔 쓰는 표기)

**기하적 의미**: 일변수 $f'(a)$ = 곡선 위 점에서 접선의 기울기. 이변수에서는

- $f_x(a, b)$: 곡면을 $y = b$인 평면($x$축과 나란한 단면)으로 자른 곡선의, 점 $(a, b, f(a,b))$에서 접선 기울기
- $f_y(a, b)$: $x = a$인 평면($y$축과 나란한 단면)으로 자른 곡선의 접선 기울기

**수업 예제**

| 함수 | $f_x$ | $f_y$ (및 $f_z$) | 쓴 규칙 |
|---|---|---|---|
| $4 - x^2 - 2y^2$ | $-2x$ | $-4y$ | 상수 미분 = 0 |
| $\sin\!\left(\dfrac{x}{1+y}\right)$ | $\cos\!\left(\dfrac{x}{1+y}\right) \cdot \dfrac{1}{1+y}$ | $\cos\!\left(\dfrac{x}{1+y}\right) \cdot \dfrac{-x}{(1+y)^2}$ | 합성함수 미분, $\left(\frac{1}{g}\right)' = -\frac{g'}{g^2}$ |
| $e^{xy}\ln z$ | $y\,e^{xy}\ln z$ | $f_y = x\,e^{xy}\ln z$, $f_z = \dfrac{e^{xy}}{z}$ | 변수 3개도 같은 방법 |

## 9. 2계 편도함수와 클레로 정리

$f(x, y) = x^3 + x^2y^3 - 2y^2$

| | 결과 |
|---|---|
| $f_x$ | $3x^2 + 2xy^3$ |
| $f_y$ | $3x^2y^2 - 4y$ |
| $f_{xx}$ | $6x + 2y^3$ |
| $f_{yy}$ | $6x^2y - 4$ |
| $f_{xy} = (f_x)_y$ | $6xy^2$ |
| $f_{yx} = (f_y)_x$ | $6xy^2$ |

**클레로(Clairaut) 정리**: $f_{xy}$, $f_{yx}$가 연속이면 $f_{xy} = f_{yx}$ (미분 순서를 바꿔도 같다). 연속이 아니면 일반적으로 같다는 보장이 없다.

## 선형대수와 연결

- 이변수 극한의 $\sqrt{(x-a)^2 + (y-b)^2}$는 6주차의 **유클리드 거리** $\lVert (x, y) - (a, b) \rVert$다
- 편도함수를 모은 벡터 $\nabla f = (f_x, f_y)$가 그래디언트. 7주차 최소제곱법에서 오차 $\lVert A\mathbf{x} - \mathbf{b} \rVert^2$를 각 변수로 편미분해 0으로 놓으면 정규방정식 $A^TA\mathbf{x} = A^T\mathbf{b}$가 나온다
- 딥러닝의 경사하강법은 이 그래디언트의 반대 방향으로 조금씩 움직여 오차를 줄인다
