## 1. 기저 (Basis)

| 용어 | 뜻 |
|---|---|
| 기저 | 공간 $V$를 생성하면서 일차독립인 벡터 집합 |
| 생성 | $V$의 모든 벡터를 이 벡터들의 선형결합으로 만들 수 있다 ($\text{span}(S) = V$) |
| 일차독립 | 다른 벡터들로 만들어지는 쓸모없는 벡터가 없다 (9주차) |

- 공간을 재는 최소한의 잣대: 하나라도 빼면 공간을 다 채우지 못하고, 하나라도 더하면 종속이 된다
- 같은 공간의 기저는 무수히 많지만 벡터 개수는 항상 같다 (→ 5절 차원)

## 2. 좌표벡터 — 기저가 있으면 벡터를 숫자로 바꿀 수 있다

**유일성 정리**: $S = \{v_1, \ldots, v_n\}$이 기저이면 $v = c_1v_1 + \cdots + c_nv_n$을 만족하는 $c$는 한 가지뿐이다. 이 $c$를 모은 것이 좌표벡터 $[v]_S = (c_1, \ldots, c_n)$이다. 증명: [proofs.md 9번](proofs.md)

- 좌표 = 레시피: "재료 $v_1$을 $c_1$번, $v_2$를 $c_2$번"
- 같은 점이라도 기저가 바뀌면 좌표가 바뀐다

| 기저 | $v = (5, 1)$의 좌표 | 확인 |
|---|---|---|
| 표준기저 $e_1, e_2$ | $(5, 1)$ | $5e_1 + 1e_2$ |
| $S = \{(1,1), (1,-1)\}$ | $(3, 2)$ | $3(1,1) + 2(1,-1) = (5,1)$ |

**좌표 구하는 법**: 성분마다 식을 하나씩 세운다 (1번째 성분끼리, 2번째 성분끼리). 식의 계수와 부호는 재료 벡터의 성분에서 온다.

$v = (7, 4)$, $S = \{v_1 = (1,2),\ v_2 = (3,1)\}$

$$c_1\begin{bmatrix}1\\2\end{bmatrix} + c_2\begin{bmatrix}3\\1\end{bmatrix} = \begin{bmatrix}7\\4\end{bmatrix}$$

$$\begin{cases} c_1 + 3c_2 = 7 & \text{(1번째 성분: } v_1, v_2 \text{의 1번째 성분 1, 3)}\\ 2c_1 + c_2 = 4 & \text{(2번째 성분: } v_1, v_2 \text{의 2번째 성분 2, 1)} \end{cases} \Rightarrow c = (1, 2)$$

검산: $1(1,2) + 2(3,1) = (7,4)$ ✓

**왜 필요한가**: 다항식·행렬 같은 추상 벡터도 좌표로 바꾸면 $\mathbb{R}^n$에서 하던 계산(det, 소거)을 그대로 쓸 수 있다. 9주차 예제 4-1에서 다항식을 계수 벡터로 바꾼 것이 바로 표준기저 $\{1, x, x^2\}$에 대한 좌표다.

## 3. 표준기저 (예제 1)

| 공간 | 표준기저 | 좌표 | 차원 |
|---|---|---|---|
| $\mathbb{R}^n$ | $e_1, \ldots, e_n$ | 성분 그대로 | $n$ |
| $P_n(x)$ | $1, x, \ldots, x^n$ | 계수 $(a_0, \ldots, a_n)$ | $n + 1$ |
| $M_{2\times 2}$ | $E_{11}, E_{12}, E_{21}, E_{22}$ | 성분 4개 | 4 |
| $\{0\}$ | 없음 (공집합) | — | 0 |

- $P_n$의 차원이 $n + 1$인 이유: 상수항 $1$도 기저에 들어간다 ($P_2$: $1, x, x^2$ → 3개)
- 예: $3 + 2x - x^2$의 표준기저 좌표 = $(3, 2, -1)$

## 4. 기저 판정 (예제 2)

$\mathbb{R}^n$에 벡터가 정확히 $n$개이면, 열로 세운 행렬 $A$의 $\det A \neq 0$ 하나로 두 조건을 같이 확인한다.

| $\det A \neq 0$이면 | 그래서 |
|---|---|
| $Ac = 0$의 해가 $c = 0$뿐 | 일차독립 |
| 모든 $b$에 대해 $Ac = b$의 해 $c = A^{-1}b$가 있음 | 생성 |

교안 질문 "det ≠ 0만으로 왜 모든 $b$를 만들 수 있나?" → 역행렬이 있으면 레시피 $c = A^{-1}b$를 항상 계산할 수 있기 때문이다.

$$v_1 = (1,0,1),\ v_2 = (1,1,0),\ v_3 = (0,1,1):\quad \det\begin{bmatrix}1&1&0\\0&1&1\\1&0&1\end{bmatrix} = 1(1 - 0) - 1(0 - 1) + 0 = 2 \neq 0 \Rightarrow \text{기저}$$

- 다항식도 계수 벡터로 바꾸면 같다: $\{1 + x,\ x + x^2,\ 1 + x^2\}$ → $(1,1,0), (0,1,1), (1,0,1)$ → 예제 2와 같은 세 벡터 → $P_2$의 기저
- 벡터 개수가 $n$이 아니면 정방행렬이 아니라 det를 못 쓴다 → rank로 판정 (rank = 벡터 개수면 독립)

## 5. 차원과 평면의 기저 (예제 3)

- 차원 $\dim V$ = 기저 벡터의 개수. 기저는 여러 개여도 개수는 항상 같다 (차원의 불변성)
- $\mathbb{R}^3$ 안 부분공간의 차원: 원점 0, 직선 1, 평면 2, 전체 3 (9주차의 4종류와 같은 목록)

**예제 3**: $W = \{(x,y,z) \mid 2x - y + 3z = 0\}$의 기저와 차원

```text
① 식 1개, 미지수 3개 → 자유변수 3 - 1 = 2개 → dim W = 2
② 계수가 ±1인 변수(y)를 나머지로 정리: y = 2x + 3z   (x, z가 자유변수)
③ 단위 대입법: 자유변수 (x, z)에 (1, 0), (0, 1)을 차례로 넣는다
     (x, z) = (1, 0) → y = 2 → v1 = (1, 2, 0)
     (x, z) = (0, 1) → y = 3 → v2 = (0, 3, 1)
④ 검산: 원래 식에 대입  2(1) - 2 + 3(0) = 0 ✓,  2(0) - 3 + 3(1) = 0 ✓
```

- "= 0"이 중요하다: 원점을 지나야 부분공간이다 (수업 강조, 9주차 영벡터 조건)
- 자유변수 자리에 (1, 0), (0, 1)이 들어가므로 두 벡터는 따로 검산하지 않아도 일차독립이다
- 기저는 답이 여러 개일 수 있지만 (다른 변수를 정리하면 다른 벡터가 나옴), 개수 2는 같다
- 실습 과제 1: $x + 2y - z = 0$ → $z = x + 2y$ → $w_1 = (1, 0, 1)$, $w_2 = (0, 1, 2)$. 법선 $n = (1, 2, -1)$과 내적이 0이다 (7주차: 평면 위의 벡터는 법선과 수직)

## 6. 랭크-퇴화차수 정리 (Rank-Nullity)

$$\text{rank}(A) + \text{nullity}(A) = n \quad (n = A\text{의 열 개수})$$

| 용어 | 뜻 | 세는 법 |
|---|---|---|
| 피벗 | 소거한 뒤 각 행에서 처음 나오는 0이 아닌 수 (계단의 첫 칸) | — |
| rank $= \dim C(A)$ | 살아남는 출력 방향 수 | 피벗 개수 = 소거 후 0이 아닌 행 수 |
| nullity $= \dim N(A)$ | 0으로 사라지는 입력 방향 수 | 자유변수 개수 = $n$ − rank |

**예제 4**: $A = \begin{bmatrix}1&2&3\\2&4&6\end{bmatrix}$ → $R_2 - 2R_1$ → $\begin{bmatrix}1&2&3\\0&0&0\end{bmatrix}$ → rank 1, 자유변수 $x_2, x_3$ → nullity 2 → $1 + 2 = 3$ ✓

**확인 문제**: $\begin{bmatrix}1&2&0&1\\0&1&1&0\\1&3&1&1\end{bmatrix}$

```text
R3 - R1 → (0, 1, 1, 0)
R3 - R2 → (0, 0, 0, 0)      ← 3행 = 1행 + 2행이었다
0이 아닌 행 2개 → rank = 2,  nullity = 4 - 2 = 2
```

- 소거 전에는 모든 행이 0이 아니어 보여도, 다른 행들의 조합인 행은 소거하면 0이 된다
- nullity는 "식 개수"가 아니라 "열 개수 − rank"로 센다

## 7. 직교·정규직교와 좌표 공식

| 용어 | 조건 | 예 |
|---|---|---|
| 직교 집합 | 서로 다른 두 벡터의 내적이 모두 0 | $(1,1), (1,-1)$ |
| 정규직교 집합 | 직교 + 모든 벡터의 길이가 1 | $\frac{1}{\sqrt2}(1,1),\ \frac{1}{\sqrt2}(1,-1)$ |
| 크로네커 델타 $\delta_{ij}$ | $i = j$면 1, 아니면 0 | 단위행렬 $I$의 성분 |

- 정규직교 = $q_i \cdot q_j = \delta_{ij}$ (자기 자신과의 내적은 1, 다른 벡터와는 0)
- 정규화 = 길이로 나누기: $q = u / \lVert u \rVert$ (곱하면 오히려 길어진다)
- 0이 아닌 벡터들의 직교 집합은 항상 일차독립이다 ([proofs.md 11번](proofs.md))

**좌표 공식**: 정규직교기저면 연립방정식이 필요 없다

| 기저 | $c_i$ | 이유 |
|---|---|---|
| 아무 기저 | 연립방정식 $Ac = v$ → $c = A^{-1}v$ | 2절 |
| 직교기저 ($u_i$) | $c_i = \dfrac{v \cdot u_i}{u_i \cdot u_i}$ | 양변에 $u_i$를 내적하면 다른 벡터와의 내적은 0 |
| 정규직교기저 ($q_i$) | $c_i = v \cdot q_i$ | 분모 $q_i \cdot q_i = 1$ ([proofs.md 10번](proofs.md)) |

예: $v = (5, 1)$, $q_1 = \frac{1}{\sqrt2}(1,1)$, $q_2 = \frac{1}{\sqrt2}(1,-1)$

$$c_1 = v \cdot q_1 = \frac{5 + 1}{\sqrt2} = 3\sqrt2,\qquad c_2 = v \cdot q_2 = \frac{5 - 1}{\sqrt2} = 2\sqrt2$$

같은 방향의 $(1,1), (1,-1)$로 구한 좌표 $(3, 2)$에 $\sqrt2$가 곱해졌다. 재료의 길이가 $\frac{1}{\sqrt2}$배로 줄었으니 $\sqrt2$배 더 많이 써야 같은 $v$가 된다.

## 8. 직교행렬

정규직교 벡터를 열로 세운 정방행렬 $Q = [q_1\ \cdots\ q_n]$

$$Q^TQ = I \iff Q^{-1} = Q^T$$

- $Q^TQ$의 $(i, j)$ 성분이 $q_i \cdot q_j = \delta_{ij}$라서 $I$가 된다
- 좌표: $c = Q^Tv$, 되돌리기: $v = Qc$
- 2×2 판정: ① 두 열의 길이가 모두 1 ② 두 열의 내적이 0

**대칭($Q = Q^T$)과는 다른 말이다**

| 행렬 | 대칭? | 직교? |
|---|---|---|
| $\begin{bmatrix}1&1\\1&-1\end{bmatrix}$ | O | X ($Q^TQ = 2I$, 열 길이가 $\sqrt2$) |
| $\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ (90° 회전) | X | O |
| $\frac{1}{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}$ | O | O |

**3대 불변성** (중간고사 증명과 같은 내용 → [proofs.md 3·4·12번](proofs.md))

| 성질 | 식 | 뜻 |
|---|---|---|
| 길이 보존 | $\lVert Qx \rVert = \lVert x \rVert$ | 늘이거나 줄이지 않는다 |
| 내적·각도 보존 | $(Qx) \cdot (Qy) = x \cdot y$ | 모양이 찌그러지지 않는다 |
| $\det Q = \pm 1$ | $+1$ 회전, $-1$ 반사 | 부피 보존 |

- 거꾸로는 성립하지 않는다: $\det = 1$이어도 직교가 아닐 수 있다 ($\begin{bmatrix}2&0\\0&1/2\end{bmatrix}$)

## 9. 그람-슈미트 직교화

**목표**: 서로 수직이 아닌 독립 재료 $v_1, \ldots, v_n$ → 서로 수직이고 길이 1인 $q_1, \ldots, q_n$. 만드는 공간(span)은 그대로다.

- "벡터 하나로 수직인 벡터를 찾는 방법"이 아니라 **벡터 집합을 같은 공간의 정규직교 집합으로 바꾸는 방법**이다
- 쓰는 도구는 6주차 정사영(그림자) 하나뿐이다

**매 단계 하는 일 3가지**

| 순서 | 하는 일 | 식 | 뜻 |
|---|---|---|---|
| ① | 그림자 길이 | $v_k \cdot q_j$ | $v_k$를 $q_j$ 직선에 수직으로 내린 곳까지의 거리 (숫자) |
| ② | 남은 조각 | $u_k = v_k - \sum_{j<k}(v_k \cdot q_j)\,q_j$ | 그림자 화살표를 빼고 남은 부분, 앞의 $q$들과 수직 |
| ③ | 길이 1로 | $q_k = u_k / \lVert u_k \rVert$ | 정규화 |

```text
v_k = (앞에서 만든 q들 방향의 그림자) + (남은 조각)
               바닥 위에 누운 부분          바닥과 직각 → 다음 q의 방향
```

- 그림자 화살표 = 그림자 길이 × $q$ (길이 × 방향). 그래서 이 $q$는 길이가 1이어야 한다
- 1단계는 뺄 것이 없어 정규화만, 2단계는 그림자 1개, 3단계는 그림자 2개를 뺀다 (바닥이 직선 → 평면)
- 남은 조각이 앞의 $q$들과 수직인 이유: [proofs.md 13번](proofs.md)

**예제 5**: $v_1 = (1,1,0)$, $v_2 = (1,0,1)$, $v_3 = (0,1,1)$의 정규직교기저

1단계

$$u_1 = v_1 = \begin{bmatrix}1\\1\\0\end{bmatrix},\qquad \lVert u_1 \rVert = \sqrt2,\qquad q_1 = \frac{1}{\sqrt2}\begin{bmatrix}1\\1\\0\end{bmatrix}$$

2단계

$$v_2 \cdot q_1 = \frac{1 + 0 + 0}{\sqrt2} = \frac{1}{\sqrt2}\qquad \text{(그림자 길이)}$$

$$u_2 = \begin{bmatrix}1\\0\\1\end{bmatrix} - \frac{1}{2}\begin{bmatrix}1\\1\\0\end{bmatrix} = \begin{bmatrix}1/2\\-1/2\\1\end{bmatrix}\qquad \left(\text{그림자 화살표} = \tfrac{1}{\sqrt2}\,q_1,\ \ \tfrac{1}{\sqrt2} \times \tfrac{1}{\sqrt2} = \tfrac12\right)$$

$$\lVert u_2 \rVert = \sqrt{\tfrac14 + \tfrac14 + 1} = \frac{\sqrt6}{2},\qquad q_2 = \frac{1}{\sqrt6}\begin{bmatrix}1\\-1\\2\end{bmatrix}$$

3단계

$$v_3 \cdot q_1 = \frac{0 + 1 + 0}{\sqrt2} = \frac{1}{\sqrt2},\qquad v_3 \cdot q_2 = \frac{0 - 1 + 2}{\sqrt6} = \frac{1}{\sqrt6}$$

$$u_3 = \begin{bmatrix}0\\1\\1\end{bmatrix} - \frac12\begin{bmatrix}1\\1\\0\end{bmatrix} - \frac16\begin{bmatrix}1\\-1\\2\end{bmatrix} = \frac16\begin{bmatrix}0 - 3 - 1\\6 - 3 + 1\\6 - 0 - 2\end{bmatrix} = \begin{bmatrix}-2/3\\2/3\\2/3\end{bmatrix}$$

$$\lVert u_3 \rVert = \frac23\sqrt{1 + 1 + 1} = \frac{2}{\sqrt3},\qquad q_3 = \frac{1}{\sqrt3}\begin{bmatrix}-1\\1\\1\end{bmatrix}$$

검산: $q_1 \cdot q_2 \propto 1 - 1 + 0 = 0$, $q_1 \cdot q_3 \propto -1 + 1 + 0 = 0$, $q_2 \cdot q_3 \propto -1 - 1 + 2 = 0$, 길이 $\frac{2}{2} = \frac{6}{6} = \frac{3}{3} = 1$ ✓

- 왜 $\frac{1}{\sqrt2}$이 아니라 $\frac12$을 빼나 (수업에서도 나온 질문): 그림자 화살표 $(v_2 \cdot q_1)\,q_1$에서 $\frac{1}{\sqrt2}$이 그림자 길이에 한 번, $q_1$ 안에 한 번 들어 있어서 두 번 곱해진다
- 계산 팁: 남은 조각은 마지막에 길이를 맞추니까 $(\frac12, -\frac12, 1) \to (1, -1, 2)$처럼 정수배로 바꿔 써도 된다. 단, 그림자 길이를 구할 때는 길이 1인 $q$를 써야 한다

**교안 방식 vs 길이를 안 맞추는 방식** (편입수학 인강에서 본 $w$ 방식)

| | 교안 ($q$, 정규직교화) | $w$ (직교화만) |
|---|---|---|
| 그림자 화살표 | $(v \cdot q)\,q$ — 분모 없음 | $\dfrac{v \cdot w}{w \cdot w}\,w$ — 분모 있음 |
| 길이 맞추기 | 매 단계 | 마지막에 한 번 (필요할 때만) |
| 예제 5 결과 | $q_1, q_2, q_3$ | $w_1 = (1,1,0),\ w_2 = (\frac12, -\frac12, 1),\ w_3 = (-\frac23, \frac23, \frac23)$ = 교안의 $u_1, u_2, u_3$ |

- $q$는 $q \cdot q = 1$이라서 $w$ 공식의 분모가 사라진 것이 교안 공식이다. 두 공식을 섞으면 틀린다
- "직교기저를 구하라"면 $w$까지, "정규직교기저를 구하라"면 마지막에 각각 길이로 나눈다

**주의**
- 순서를 바꾸면 결과가 달라진다: $(1,2), (3,1)$ 순서 → $q_2 \propto (2, -1)$, $(3,1), (1,2)$ 순서 → $q_2 \propto (-1, 3)$
- 재료가 종속이면 어떤 단계의 남은 조각이 $0$이 되어 길이로 나눌 수 없다 (그래서 독립인 재료가 필요)
- 앞의 $k$개 $q$는 앞의 $k$개 $v$와 같은 공간을 만든다

## 10. QR 분해와 최소제곱

그람-슈미트 계산 중에 나온 숫자를 모으면 행렬 분해가 된다.

$$A = [v_1\ v_2\ v_3] = QR = [q_1\ q_2\ q_3]\begin{bmatrix} v_1\cdot q_1 & v_2\cdot q_1 & v_3\cdot q_1\\ 0 & v_2\cdot q_2 & v_3\cdot q_2\\ 0 & 0 & v_3\cdot q_3\end{bmatrix}$$

- $R$의 $j$번째 열 = $v_j$의 $q$-좌표 (7절 좌표 공식 $c_i = v \cdot q_i$)
- 대각 위 = 그림자 길이, 대각 = 남은 조각의 길이 $\lVert u_k \rVert$ (0이 아니라서 $R$은 가역)
- 대각 아래가 0인 이유: $v_k$는 $q_1 \sim q_k$만으로 만들어진다 (뒤의 $q$ 방향 그림자는 0)

예제 5:

$$R = \begin{bmatrix}\sqrt2 & \frac{1}{\sqrt2} & \frac{1}{\sqrt2}\\[2pt] 0 & \frac{\sqrt6}{2} & \frac{1}{\sqrt6}\\[2pt] 0 & 0 & \frac{2}{\sqrt3}\end{bmatrix}$$

**최소제곱** (7주차 연결): $Ax = b$ → $QRx = b$ → 양변에 $Q^T$ → $Rx = Q^Tb$. $R$이 위삼각이라 아래 행부터 거꾸로 대입하면 끝난다. 정규방정식 $A^TAx = A^Tb$와 같은 답이 나온다 (코드에서 점 (1,2), (2,3), (3,5), (4,6)으로 확인: $y = 0.5 + 1.4x$).

## 11. 파이썬

```python
import numpy as np
import sympy as sym

# SymPy: 분수·루트를 그대로 유지한 정확한 정규직교기저
basis = [sym.Matrix([1, 1, 0]), sym.Matrix([1, 0, 1]), sym.Matrix([0, 1, 1])]
q = sym.GramSchmidt(basis, orthonormal=True)    # orthonormal=True: 길이 1까지 맞춤

# NumPy: 수치 QR 분해
A = np.column_stack(([1, 1, 0], [1, 0, 1], [0, 1, 1])).astype(float)   # 열 = v1, v2, v3
Q, R = np.linalg.qr(A)
print(np.allclose(Q.T @ Q, np.eye(3)), np.allclose(Q @ R, A))         # True True
```

| 함수 | 하는 일 |
|---|---|
| `sym.GramSchmidt(벡터 리스트, orthonormal=True)` | 그람-슈미트 (정확한 값) |
| `np.linalg.qr(A)` | $A = QR$ 분해 (Householder 방식, 수치 오차에 강함) |
| `scipy.linalg.orth(A)` | 열공간의 정규직교기저 (SVD 기반) |
| `sym.Matrix(A).columnspace()` / `.nullspace()` | 열공간·영공간 기저 (실습 미션 2) |

- `np.linalg.qr`의 $Q$ 열과 $R$ 대각은 **부호가 손계산과 반대**로 나올 수 있다 (예제 5에서 $R_{11} = -\sqrt2$). 열 하나에 $-1$을 곱해도 정규직교인 것은 같으니 틀린 것이 아니다. 손계산과 비교할 때는 부호를 맞춰서 본다
- 직접 구현 (실습 미션 3): 바깥 반복은 $v_k$, 안쪽 반복은 앞의 $q_j$ 방향 그림자를 빼기 → [코드](code/week10_basis_gram_schmidt.py)의 `gram_schmidt_orthonormal`
- 그람-슈미트를 그대로 컴퓨터로 돌리면 오차가 쌓여 직교성이 조금씩 깨진다. 그래서 라이브러리는 Householder 반사를 쓴다
