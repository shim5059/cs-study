## 1. 회선 교환 vs 패킷 교환

| 구분 | 회선 교환 (Circuit Switching) | 패킷 교환 (Packet Switching) |
|---|---|---|
| **방식** | 통신 전에 경로를 미리 예약하고 끝날 때까지 **독점** | 데이터를 패킷으로 잘게 쪼개 **그때그때 빈 길로** 전송 |
| **비유** | 옛날 유선 전화 | 인터넷 택배망 |
| **장점** | 전송 속도와 지연 시간이 일정하게 보장됨 | 여러 사용자가 회선을 나눠 써서 **효율적** |
| **단점** | 데이터를 안 보낼 때도 회선을 차지해 낭비 발생 | 패킷이 몰리면 **큐잉 지연**과 **패킷 손실** 발생 |

- 오늘날의 **인터넷(IP)** 은 **패킷 교환** 방식을 사용한다.

## 2. 성능 지표와 단위 변환

| 지표 | 의미 | 비유 |
|---|---|---|
| **대역폭(Bandwidth)** | 1초에 보낼 수 있는 **이론상 최대** 데이터 양 (bps) | 도로의 차선 수 |
| **처리량(Throughput)** | 1초에 **실제로 측정된** 데이터 전송량 (항상 대역폭 이하) | 실제로 통과한 차량 수 |
| **지연(Delay/Latency)** | 패킷이 출발지에서 목적지까지 도착하는 데 걸리는 시간 | 이동 시간 |
| **지터(Jitter)** | 지연 시간이 **들쭉날쭉하게 흔들리는 정도** | 도착 간격의 불규칙성 |

- **단위 변환**: 소문자 `b` = bit, 대문자 `B` = Byte ($1\text{ Byte} = 8\text{ bit}$)
  - 예: $200\text{ Mbps} \div 8 = 25\text{ MB/s}$
- **지터가 중요한 서비스**: 실시간 음성 통화(VoIP), 화상회의, 온라인 게임

## 3. 지연(Delay)의 4가지 종류

패킷 하나가 라우터를 거쳐 다음 라우터로 이동할 때 순서대로 발생하는 4가지 지연이다.

```text
[라우터 도착]
  │ ① 처리 지연 (Processing)   헤더를 읽고 어디로 보낼지 결정 + 비트 오류 검사
  │ ② 큐잉 지연 (Queuing)      출력 링크로 나가기 위해 버퍼(큐)에서 줄 서서 기다리는 시간
  │ ③ 전송 지연 (Transmission) 패킷의 모든 비트를 선로에 밀어 올리는 시간 (= 패킷 크기 L / 대역폭 R)
  ↓ ④ 전파 지연 (Propagation)  전기·빛 신호가 물리적 매체를 따라 이동하는 시간 (= 거리 d / 신호 속도 s)
[다음 라우터]
```

## 4. 인터넷 생태계 (ISP · AS · IX · CDN)

| 용어 | 의미 |
|---|---|
| **ISP(인터넷 서비스 제공자)** | 개인·기업에 인터넷 접속을 제공하는 통신사 (KT, SKB, LG U+ 등) |
| **AS(자율 시스템)** | 하나의 관리 주체 아래 **동일한 라우팅 정책**으로 운영되는 네트워크 덩어리 |
| **IX(인터넷 교환점)** | 여러 ISP(AS)가 만나 트래픽을 **직접 교환**하는 물리적 환적장 |
| **CDN(콘텐츠 전송 네트워크)** | 원본 서버 대신 **사용자와 가까운 지역 캐시 서버**에 복사본을 두어 전달하는 기술 |

- **CDN이 필요한 3가지 관점**:
  1. **지연**: 가까운 캐시 서버에서 받으므로 물리적 거리가 줄어 지연 감소
  2. **트래픽**: 요청이 여러 캐시 서버로 분산되어 원본 서버와 백본망 부담 감소
  3. **가용성**: 특정 서버에 장애가 나도 다른 캐시 서버가 대신 응답하여 서비스 유지

## 5. 네트워크 진단 명령어와 트러블슈팅

| 명령어 | 확인하는 정보 | 관련 프로토콜 |
|---|---|---|
| `ipconfig` | 내 PC의 **IP 주소, 서브넷 마스크, 기본 게이트웨이** 확인 | — |
| `ping` | 목적지까지 **도달 가능 여부**와 **왕복 시간(RTT)**, 손실률 측정 | ICMP |
| `tracert` | 목적지까지 거쳐 가는 **라우터 경로(홉 목록)** 와 구간별 응답 시간 확인 | ICMP |
| `nslookup` | 도메인 이름을 조회하여 **IP 주소**와 응답한 DNS 서버 확인 | DNS |

- **169.254.x.x (APIPA)**: 공유기 등의 **DHCP 서버로부터 IP 주소를 할당받지 못했을 때** OS가 임시로 붙이는 주소 (외부 인터넷 통신 불가)

## 6. Wireshark 필터

| 구분 | 동작 시점 | 설명 및 예시 |
|---|---|---|
| **캡처 필터** | 캡처 **시작 전** | 조건에 맞는 패킷만 수집·저장 (나머지는 아예 버림) |
| **디스플레이 필터** | 캡처 **완료 후** | 수집된 전체 패킷 중 화면에 **보여줄 것만 골라냄** (예: `dns`, `tcp.port == 443`) |
