# 01 · Linux 명령어

> 헷갈렸던 부분: [deep-dive.md](deep-dive.md)
>
> 명령어마다 **무엇을 하는지 + 이름이 어디서 왔는지**를 같이 보면 이름만으로 기능이 떠오른다

## 1. 위치 · 이동

| 명령어 | 무엇을 하나 | 이름의 뜻 |
|---|---|---|
| `pwd` | **현재 위치(경로)를 표시** | **P**rint **W**orking **D**irectory |
| `cd 경로` | 디렉터리 **이동** (`cd ..` 위로, `cd ~` 홈) | **C**hange **D**irectory |
| `ls` | 파일·폴더 **목록** (`-l` 자세히, `-a` 숨김 포함) | **L**i**s**t |

## 2. 파일 · 폴더 다루기

| 명령어 | 무엇을 하나 | 이름의 뜻 |
|---|---|---|
| `mkdir 이름` | 디렉터리 **만들기** | **M**a**k**e **Dir**ectory |
| `rmdir 이름` | **빈** 디렉터리 삭제 | **R**e**m**ove **Dir**ectory |
| `touch 파일` | **빈 파일** 만들기 (있으면 수정 시간만 갱신) | 살짝 건드림 |
| `cp 원본 대상` | **복사** (`-r` 폴더째) | **C**o**p**y |
| `mv 원본 대상` | **이동** 또는 **이름 바꾸기** | **M**o**v**e |
| `rm 파일` | **삭제** (`-r` 폴더째, `-f` 강제) | **R**e**m**ove |

- 이름 바꾸기 전용 명령은 없고 `mv a.txt b.txt`로 한다

## 3. 내용 보기 · 찾기

| 명령어 | 무엇을 하나 |
|---|---|
| `cat 파일` | 파일 **내용 전체** 출력 (con**cat**enate) |
| `head` / `tail` | 앞 / 뒤 일부 출력 (기본 10줄) |
| `more` / `less` | 한 화면씩 넘겨 보기 |
| `grep 단어 파일` | 그 단어가 있는 **줄** 찾기 |
| `find 위치 -name 이름` | 파일 **위치** 찾기 |
| `echo 문자열` | **내가 쓴 문자열·변수 값**을 출력 |

## 4. 권한 · 소유자

| 명령어 | 무엇을 하나 | 이름의 뜻 |
|---|---|---|
| `chmod` | 접근 **권한**(읽기·쓰기·실행) 변경 | **Ch**ange **Mod**e |
| `chown` | **소유자** 변경 | **Ch**ange **Own**er |

## 5. 프로세스 · 시스템 · 네트워크 · 편집

| 명령어 | 무엇을 하나 |
|---|---|
| `ps` | 프로세스 목록 **한 번** (사진) |
| `top` | 프로세스·CPU를 **실시간으로 계속** (영상) |
| `kill PID` | 번호로 프로세스 종료 |
| `clear` | 화면 지우기 |
| `man 명령어` | 설명서 (**Man**ual) |
| `ifconfig` | 네트워크 인터페이스 설정(IP 주소, 서브넷 마스크, MAC 주소 등) 확인·변경 (**I**nter**f**ace **Config**ure). 윈도우는 `ipconfig` |
| `ping 주소` | 상대와 통신되는지 확인 |
| `who` | 지금 **로그인한 사용자** 목록 |
| `fsck` | **파일 시스템** 검사·복구 (**F**ile **S**ystem **C**hec**k**) |
| `df` / `du` | 디스크 남은 용량 (**D**isk **F**ree) / 파일·디렉터리 사용량 (**D**isk **U**sage) |
| `free` | 메모리 사용량 |
| `passwd` | 비밀번호 변경 |
| `su` / `sudo` | 다른 사용자로 전환 / 관리자 권한으로 한 번 실행 |
| `history` | 지금까지 입력한 명령 기록 |
| `wc 파일` | 줄·단어·글자 수 세기 (**W**ord **C**ount) |
| `tar` | 여러 파일을 하나로 묶기 |
| `vi 파일` | 터미널 텍스트 편집기 (`i` 입력, `ESC` 명령 모드, `:wq` 저장 후 종료, `:q!` 저장 없이 종료) |

**구별법**: "프로세스" → `ps`·`top`·`kill`, "파일 시스템" → `fsck`, "사용자" → `who`, "IP·MAC·인터페이스" → `ifconfig`, "연결 확인" → `ping`

## 6. 환경 변수

환경 변수 = 셸이 기억해 두는 **설정값 이름표**. 대표가 `PATH`(명령어를 찾을 디렉터리 목록), `HOME`(홈 경로)

| 명령어 | 무엇을 하나 | 예 |
|---|---|---|
| `export` | 환경 변수 **설정** | `export PATH=/usr/bin` |
| `env` / `printenv` | 환경 변수 **전체 목록** 출력 | `env`, `printenv PATH` |
| `echo $변수` | 변수 **하나의 값** 출력 | `echo $HOME` |
| `unset` | 환경 변수 **삭제** | `unset MYVAR` |

- `PATH`는 **명령어가 아니라 변수 이름**이다. "명령어를 쓰시오"에 `PATH`를 쓰면 틀린다
- 리눅스는 대소문자를 구분한다: `PATH`와 `path`는 다른 변수

## 7. 명령문으로 쓰기: 명령어 + 공백 + 대상

명령어 이름만이 아니라 "명령문"을 쓰라고 하면 **대상(파일·디렉터리 이름)까지** 붙인다

| 하고 싶은 일 | 명령문 |
|---|---|
| data1 디렉터리를 만든다 | `mkdir data1` |
| (비어 있는) data2 디렉터리를 삭제한다 | `rmdir data2` |
| 부모 디렉터리로 이동한다 | `cd ..` |
| a.txt를 삭제한다 | `rm a.txt` |
| a.txt를 b.txt로 복사한다 / 이름을 바꾼다 | `cp a.txt b.txt` / `mv a.txt b.txt` |
| a.txt 내용을 출력한다 | `cat a.txt` |
| 소유자를 user1로 바꾼다 | `chown user1 a.txt` |
| 모두에게 실행 권한을 추가한다 | `chmod a+x run` |

- `cp`·`mv`는 **원본 → 대상** 순서, `chmod`·`chown`은 **권한(사람) → 파일** 순서
- "(비어 있는)"이 붙으면 `rmdir`. `rm -r`은 안의 내용까지 통째로 지운다
