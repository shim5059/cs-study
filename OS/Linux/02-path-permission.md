# 02 · 경로와 권한

> 헷갈렸던 부분: [deep-dive.md](deep-dive.md)

## 1. 경로

| 기호 | 뜻 |
|---|---|
| `/` (맨 앞) | **루트**. 이걸로 시작하면 **절대 경로** |
| `.` | 현재 디렉터리 (제자리) |
| `..` | **부모** 디렉터리 (한 칸 위) |
| `~` | 내 홈 디렉터리 |

- 절대 경로: 루트부터 전부 (`/Users/user/src/test`) — 어디서 봐도 같은 곳
- 상대 경로: 현재 위치 기준 (`../src/test`) — `/`로 시작하지 않음

### 상대 → 절대 바꾸기: 조각 하나씩

| 조각 | 할 일 |
|---|---|
| `..` | 맨 뒤 이름 **하나 지우기** |
| `.` | 아무것도 안 함 |
| 이름 | 맨 뒤에 붙이기 |

**공단 예시문제 1번**: 현재 `/Users/user/workspace`, `../src/test`

| 조각 | 위치 |
|---|---|
| 시작 | `/Users/user/workspace` |
| `..` | `/Users/user` |
| `src` | `/Users/user/src` |
| `test` | `/Users/user/src/test` |

현재 `/home/kim/docs`, `../../lee/./pics` → `/home/kim` → `/home` → `/home/lee` → (그대로) → **`/home/lee/pics`**

- 루트에서 `..`을 하면 그대로 루트

## 2. 권한

### 왜 쓰나
여러 사람이 컴퓨터 한 대를 같이 쓸 때, 내 파일을 남이 보거나 지우지 못하게 파일마다 **"누가 무엇을 할 수 있는지" 체크표**를 붙여 둔다. 그 표를 바꾸는 명령이 `chmod`.

### 체크표 = 3명 × 3가지 = 9칸

| | 읽기 r (4) | 쓰기 w (2) | 실행 x (1) |
|---|---|---|---|
| 주인 u | | | |
| 그룹 g | | | |
| 기타 o | | | |

`ls -l`의 `-rwxr-xr--`는 이 9칸을 한 줄로 편 것 (맨 앞 1칸은 종류: `-` 파일, `d` 디렉터리)
- 체크된 칸은 글자, 안 된 칸은 `-` → **항상 9칸**, 순서는 언제나 r → w → x

### 숫자: 사람마다 4·2·1을 더해서 한 자리
4·2·1은 어떻게 골라 더해도 합이 겹치지 않아서(동전 4원·2원·1원) 숫자만 보고 칸을 되찾을 수 있다.

| 숫자 | 더하기 | 3칸 |
|---|---|---|
| 7 | 4 + 2 + 1 | `rwx` |
| 6 | 4 + 2 | `rw-` |
| 5 | 4 + 1 | `r-x` |
| 4 | 4 | `r--` |
| 0 | — | `---` |

| 숫자 | 9칸 | 뜻 |
|---|---|---|
| `777` | `rwxrwxrwx` | 모두 전부 가능 |
| `755` | `rwxr-xr-x` | 주인은 전부, 나머지는 읽기·실행 |
| `754` | `rwxr-xr--` | |
| `751` | `rwxr-x--x` | |
| `644` | `rw-r--r--` | 주인 읽기·쓰기, 나머지 읽기만 |
| `640` | `rw-r-----` | 기타는 아무것도 못 함 |
| `700` | `rwx------` | 주인만 |

### 기호 방식
| 명령 | 무엇을 하나 |
|---|---|
| `chmod u+x a.sh` | 주인에게 실행 **추가** |
| `chmod g-w a.txt` | 그룹 쓰기 **제거** |
| `chmod o=r a.txt` | 기타는 **읽기만** |
| `chmod a+r a.txt` | 모두(all)에게 읽기 추가 |
