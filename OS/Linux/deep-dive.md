# Linux Deep Dive

> **틀렸던 것 → 처음 생각 → 원리 → 깨달음** 순서의 기록

## 1. 명령어

### 처음 생각 (오답)
- "현재 작업 중인 디렉토리 경로를 표시" → `ls`라고 씀 (정답 `pwd`)
- "시스템 모드를 바꾸어 접근 권한을 설정·변경" → `cat`이라고 씀 (정답 `chmod`)

### 원리
| 명령어 | 무엇을 하나 | 이름 |
|---|---|---|
| `pwd` | 현재 **경로**를 보여줌 | Print Working Directory |
| `ls` | 현재 폴더 **안의 목록**을 보여줌 | List |
| `chmod` | 권한 변경 | Change **Mod**e ← 문제의 "모드"가 힌트 |
| `cat` | 파일 내용 출력 | concatenate |

### 깨달음
이름의 원래 단어를 알면 기능이 떠오른다. 이후 `pwd`/`cat`/`chmod`/`chown`, `mkdir`/`mv`/`top` 문제는 맞혔다.

## 2. 상대 경로의 `..`

### 처음 생각 (오답)
현재 `/Users/user/workspace`, 상대 경로 `../src/test`
내 답: `/Users/user/workspace/src/test` (정답 `/Users/user/src/test`)

### 원리
`..`을 무시하고 현재 위치 뒤에 그대로 붙였다. `..`은 **맨 뒤 이름 하나를 지우는** 조각이다.

| 조각 | 위치 |
|---|---|
| 시작 | `/Users/user/workspace` |
| `..` | `/Users/user` |
| `src` → `test` | `/Users/user/src/test` |

### 깨달음
조각을 하나씩 처리하는 표로 풀면 실수가 없다. `../../lee/./pics` 문제는 맞혔다.

## 3. 권한 9칸에서 `-`를 빠뜨림

### 처음 생각 (오답)
처음 설명으로는 권한이 왜 필요한지, 숫자가 뭔지 이해가 안 됐다. `chmod 640`을 `rwr---`라고 씀 (정답 `rw-r-----`)

### 원리
권한 = 3명(주인·그룹·기타) × 3가지(r·w·x) = **9칸 체크표**. 체크 안 된 칸도 `-`로 **반드시 채운다**.

| 사람 | 숫자 | 4·2·1 | 3칸 |
|---|---|---|---|
| 주인 | 6 | 4 + 2 | `rw-` |
| 그룹 | 4 | 4 | `r--` |
| 기타 | 0 | — | `---` |

### 깨달음
"777이면 다 된다"는 원래 알던 것에서 출발해, 숫자를 4·2·1로 쪼개고 사람마다 3칸씩 채우면 된다. `chmod 754` → `rwxr-xr--`는 맞혔다.

## 4. `pwd`를 또 `ls`로 (2026-11-13, 3번째)

| 문제 | 내 답 | 정답 |
|---|---|---|
| 현재 작업 중인 디렉터리의 **경로를 표시** | `ls` | **`pwd`** |

"경로" → **P**rint **W**orking **D**irectory. `ls`는 **안에 뭐가 있는지(목록)**. 문제에 "경로"가 보이면 무조건 pwd.

2026-11-14: "현재 작업 디렉터리의 절대경로를 출력"에 `pwd`, "파일 목록을 출력"에 `ls`를 연달아 맞혔다. "경로 → pwd, 목록 → ls" 연결이 잡혔다.

## 5. chmod를 명령문으로 쓰지 못했다 (2026-11-13 ~ 14)

| 문제 | 내 답 | 정답 | 틀린 이유 |
|---|---|---|---|
| 소유자에게 실행 권한 추가 (기호 모드) | `--x------ -script.sh` | `chmod u+x script.sh` | `ls -l`이 **보여 주는 모양**을 씀. 바꾸는 **명령**은 `chmod`로 시작 |
| 모두에게 실행 권한 추가 (기호 모드) | `chmod augo + x run` | `chmod a+x run` | `a`가 이미 u+g+o. 띄어 쓰면 `invalid mode` 오류 |
| 소유자 rwx, 그룹 rx, 기타 r (8진법) | `chmod u+rwx, g+rx, o+r` | `chmod 754 config.sh` | 8진법 조건 무시, 파일 이름 빠짐, 쉼표 뒤 공백 |

### 깨달음
`chmod` + 공백 + **붙여 쓴 권한** + 공백 + **파일**. "8진법·숫자" → `754` 같은 세 자리, "기호" → `u+x` 같은 글자. 8진법은 새로운 게 아니라 원래 알던 숫자 방식이었다 → [02 · 8진법](02-path-permission.md#8진법--숫자-방식)

## 7. 절대경로인데 맨 앞 `/`를 뺐다

현재 `/usr/local/bin`에서 `cd ../../share` 후의 위치를 절대경로로 → 내 답 `usr/share`, 정답 **`/usr/share`**

`/`가 없으면 **상대 경로**라서 지금 위치 안의 `usr/share`(= `/usr/local/bin/usr/share`)를 뜻한다. 절대경로는 **반드시 `/`로 시작**

---

## 8. 환경 변수 "명령어"에 변수 이름을 썼다 (2026-11-14)

환경 변수 관련 명령어를 묻는 문제에 `path`라고 씀. `PATH`는 명령을 찾을 디렉터리 목록이 담긴 **변수 이름**이지 명령어가 아니다. 설정은 `export`, 목록 출력은 `env`, 값 하나 출력은 `echo $PATH` → [01 · 환경 변수](01-commands.md#6-환경-변수). 소문자로 쓴 것도 문제: 리눅스는 대소문자를 구분한다.

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| 경로 / 목록 혼동 | 경로 → `pwd`, 목록 → `ls` |
| 권한 문자열을 답으로 씀 | 바꾸는 건 `chmod 명령문` |
| 권한 부분 띄어쓰기 | `a+x`, `754`는 붙여서 |
| 8진법이 따로 있는 줄 앎 | 8진법 = 숫자 방식 (r4 w2 x1) |
| 절대경로에 `/` 빠뜨림 | 절대경로는 `/`로 시작 |
| 변수 이름을 명령어로 씀 | 설정 `export`, 출력 `env`·`echo $변수` |
