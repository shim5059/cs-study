## 1. `k`와 `"k"`는 완전히 다른 것

### 처음 생각 (오답)
```java
int k = 5;
System.out.println("k");
```
변수 `k`에 5가 들어 있으니 `5`가 출력된다고 생각했다.

### 원리
```
 "k"  →  큰따옴표 = 문자열 리터럴  →  글자 k 그대로
  k   →  따옴표 없음 = 변수 이름   →  변수에 저장된 값 5
```

```java
int k = 5;
System.out.println("k");   // k
System.out.println(k);     // 5
```

### 깨달음
따옴표가 있으면 **글자**, 없으면 **이름(변수)**. 출력문을 읽을 때 먼저 따옴표부터 확인한다.

## 2. `+`는 왼쪽부터 하나씩 계산된다

### 처음 생각 (오답)
`a + "" + b` 같은 식에서 `+`가 숫자 덧셈인지 문자열 연결인지 섞여서 헷갈렸다.

### 원리
`+`는 **왼쪽부터 두 개씩** 계산한다. 둘 중 하나라도 문자열이면 그 순간부터 **문자열 연결**이 된다.

```java
int a = 1, b = 2;

System.out.println(a + b + "");    // (1 + 2) + ""   → "3"
System.out.println("" + a + b);    // ("" + 1) + 2   → "12"
System.out.println(a + "" + b);    // (1 + "") + 2   → "12"
```

```
a + b + ""          "" + a + b          a + "" + b
└─┬─┘               └─┬──┘              └─┬──┘
  3 (숫자)            "1" (문자열)        "1" (문자열)
  └──┬──┘             └──┬──┘             └──┬──┘
    "3"                 "12"                "12"
```

### 깨달음
`+`를 만나면 **지금까지 계산된 결과가 숫자인지 문자열인지**만 보면 된다. 한 번 문자열이 되면 그 뒤는 전부 이어 붙이기다.

## 3. `double`은 정수를 넣어도 `.0`이 붙는다

### 처음 생각 (오답)
```java
double d = 3;
System.out.println(d);
```
3을 넣었으니 `3`이 출력된다고 생각했다.

### 원리
`int` 3이 `double` 변수에 들어가면서 **자동 형 변환**(작은 타입 → 큰 타입)이 일어난다. 변수에 저장되는 값은 이미 실수 `3.0`이다.

```java
double d = 3;
System.out.println(d);       // 3.0

int x = 7;
System.out.println(x / 2);   // 3    (int / int → 소수점 버림)
System.out.println(x / 2.0); // 3.5  (int / double → double)
```

### 깨달음
출력 결과는 **변수의 타입**이 정한다. `double`이면 항상 소수점이 붙는다.

---

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| `"k"`를 변수 값으로 출력 | 따옴표 = 글자, 따옴표 없음 = 변수 |
| `+`의 덧셈·연결 혼동 | 왼쪽부터 두 개씩, 문자열이 나오면 그때부터 연결 |
| `double d = 3` → `3` | 자동 형 변환으로 `3.0` |
