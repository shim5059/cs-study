# 1주차 · 자바 시작하기

> 헷갈렸던 부분과 해결 과정: [week01-deep-dive.md](week01-deep-dive.md)

> 교재: 『미라클 자바 프로그래밍』 2장 (자료형·변수·형 변환)

## 1. 자바의 특징
- 자동 메모리 관리 (가비지 컬렉터)
- 멀티스레딩 지원
- 강력한 보안, 풍부한 표준 라이브러리
- 엄격한 타입 검사와 예외 처리

## 2. 자바 프로그램의 구조
- **객체** = 데이터(변수) + 동작(메서드)
- **클래스**: 객체의 설계도
- **패키지**: 클래스를 묶는 이름 공간

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

## 3. 이클립스 프로젝트 만들기
1. File → New → Java Project (이름 입력, `Create module-info.java` 체크 해제)
2. `src` → New → Package
3. Package → New → Class (`public static void main` 체크)

## 4. 기본 자료형

| 자료형 | 예 | 비고 |
|---|---|---|
| `int` | `10` | 정수 |
| `double` | `3.14` | 실수 |
| `char` | `'A'` | 문자 1개, 작은따옴표, 비워 둘 수 없음 |
| `boolean` | `true`, `false` | 참/거짓 |
| `String` | `"Java"` | 문자열 (기본형이 아니라 클래스) |

- `var`: 컴파일러가 대입한 값을 보고 타입을 추론 (`var n = 10;` → int)

## 5. 이스케이프 시퀀스
- `\n` 줄바꿈, `\t` 탭

## 6. 형 변환

| 종류 | 방향 | 문법 |
|---|---|---|
| 자동 형 변환 | 작은 타입 → 큰 타입 (`int` → `double`) | 자동 |
| 강제 형 변환 | 큰 타입 → 작은 타입 (`double` → `int`) | `(int) 3.7` → `3` (소수점 유실) |

```java
int i = 10;
double d = i;          // 자동: 10.0
int j = (int) 3.7;     // 강제: 3
char c = 'A';
int code = c;          // 유니코드 값: 65
```

## 8. 연산자 함정 (복습 추가)

> 실행 결과 문제에 자주 나오는 것만 모음. 모두 직접 실행해 확인

### 나눗셈 · 나머지 · 캐스팅 위치

| 코드 | 결과 | 이유 |
|---|---|---|
| `7 / 2` | `3` | 정수끼리 나누면 몫 (Python은 `3.5`) |
| `7 / 2.0` | `3.5` | 한쪽이 실수면 실수 |
| `-7 / 2` | `-3` | 0 쪽으로 버림 |
| `-7 % 2` | `-1` | 나머지 부호는 **앞 수**를 따름 |
| `(double) 7 / 2` | `3.5` | 7을 먼저 7.0으로 바꾼 뒤 나눔 |
| `(double) (7 / 2)` | `3.0` | 괄호 안 `7 / 2` = 3을 먼저 계산 |
| `5 / 2 * 2.0` | `4.0` | 왼쪽부터: 2 → 4.0 |
| `1.0 / 0` | `Infinity` | 실수 나눗셈은 예외 아님 (정수 `10 / 0`은 예외) |

### 문자열 `+`: 왼쪽부터, 문자열을 만나는 순간부터 이어 붙이기

| 코드 | 결과 |
|---|---|
| `"A" + 1 + 2` | `A12` |
| `1 + 2 + "A"` | `3A` |
| `1 + 2 + "3" + 4 + 5` | `3345` |
| `"A" + (1 + 2)` | `A3` |

### char는 숫자 (`'A'` = 65, `'a'` = 97, `'0'` = 48)

| 코드 | 결과 |
|---|---|
| `'A' + 1` | `66` (char + int → int) |
| `(char) ('A' + 1)` | `B` |
| `"" + 'A' + 1` | `A1` |
| `char c = 'A'; c += 2;` | `C` (`+=`는 자동 캐스팅) |
| `c = c + 2;` | 컴파일 에러 (int를 char에 대입) |

### `++` 전위 · 후위

| 코드 (`i = 5`에서 시작) | 결과 |
|---|---|
| `a = i++;` | `a = 5`, `i = 6` (사용 후 증가) |
| `b = ++i;` | `b = 6`, `i = 6` (증가 후 사용) |
| `j = i++ + ++i;` | `j = 12` (5 + 7), `i = 7` |
| `k = 3; k = k++;` | `k = 3` (꺼내 둔 3을 다시 대입) |

섞여 있으면 **왼쪽부터 한 칸씩** 값을 확정한다.

### 단락 평가 (short-circuit)

| 연산자 | 왼쪽이 이러면 | 오른쪽 |
|---|---|---|
| `&&` | false | **실행 안 함** |
| `\|\|` | true | **실행 안 함** |
| `&`, `\|` | 상관없이 | 항상 실행 |

```java
int x = 3, y = 5;
int z = x++ + --y;                    // 3 + 4 = 7, x = 4, y = 4
boolean r = (x > 5) && (++y > 0);     // false → ++y 실행 안 됨
System.out.println(x + " " + y + " " + z + " " + r);   // 4 4 7 false
```

### 비트 연산

| 코드 | 결과 | 계산 |
|---|---|---|
| `6 & 3` | `2` | `110 & 011 = 010` |
| `6 \| 3` | `7` | `111` |
| `6 ^ 3` | `5` | `101` |
| `1 << 3` | `8` | × 2³ |
| `16 >> 2` | `4` | ÷ 2² |
| `~5` | `-6` | `~n = -(n+1)` |

## 9. printf 서식 (복습 추가)

| 서식 | 값 | 결과 | 뜻 |
|---|---|---|---|
| `%d` | 42 | `[42]` | 정수 |
| `%5d` | 42 | `[   42]` | 5칸, 오른쪽 정렬 |
| `%-5d` | 42 | `[42   ]` | 5칸, 왼쪽 정렬 |
| `%05d` | 42 | `[00042]` | 빈칸을 0으로 |
| `%.2f` | 3.14159 | `[3.14]` | 소수점 둘째 자리 (반올림) |
| `%8.3f` | 3.14159 | `[   3.142]` | 소수점 포함 전체 8칸 |
| `%s` / `%c` | "hi" / 'Z' | `[hi]` / `[Z]` | 문자열 / 문자 |
| `%n` | | 줄바꿈 | printf는 **자동 줄바꿈 없음** |

```java
System.out.printf("[%4d][%-4d][%03d][%.1f]%n", 12, 12, 7, 2.66);
// [  12][12  ][007][2.7]
```
