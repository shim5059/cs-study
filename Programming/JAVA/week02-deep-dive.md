## 1. `if ~ else if`는 참인 것을 전부 실행하지 않는다

### 처음 생각 (오답)
조건이 여러 개 참이면 참인 블록이 **전부** 실행된다고 생각했다.

### 원리
```java
int score = 95;
if (score >= 90) {
    System.out.println("A");    // 참 → 실행하고 묶음 전체 종료
} else if (score >= 80) {
    System.out.println("B");    // 이것도 참이지만 검사조차 안 함
}
// 출력: A
```

```
if ── 참? ──예──▶ 실행 ──▶ 묶음 끝
       │
      아니오
       ▼
else if ── 참? ──예──▶ 실행 ──▶ 묶음 끝
```

### 깨달음
`else if`로 묶인 조건들은 **처음으로 참인 하나만** 실행된다. 여러 개를 실행하고 싶으면 `if`를 따로따로 써야 한다.

## 2. switch 폴스루는 "모든 case 실행"이 아니다

### 처음 생각 (오답)
서술형에서 폴스루를 "`break`가 없으면 **모든 case가 실행된다**"고 썼다.

### 원리
switch는 **값이 맞는 case로 점프**한 다음, `break`를 만날 때까지 **아래로** 내려간다. 위쪽 case는 실행되지 않는다.

```java
int n = 2;
switch (n) {
    case 1: System.out.println("one");     // 건너뜀 (위쪽)
    case 2: System.out.println("two");     // ← 여기로 점프
    case 3: System.out.println("three");   // break 없어서 계속
            break;                         // 여기서 멈춤
    default: System.out.println("etc");    // 실행 안 됨
}
// 출력: two, three
```

```
case 1   ✗ (점프해서 지나침)
case 2   ● 시작
case 3   ● 계속 (break 없음)
break    ■ 종료
default  ✗
```

- `case` 뒤에는 **값**만 올 수 있다. `case n > 3:` 같은 조건식은 안 된다.

### 깨달음
폴스루 = **맞는 case부터 break까지 아래로 흘러내림**. 시작점이 있고 끝점이 있다.

## 3. 중괄호 없는 `for`는 바로 다음 한 문장만 반복한다

### 처음 생각 (오답)
들여쓰기가 되어 있으면 반복 안에 들어간다고 생각했다.

### 원리
```java
for (int i = 0; i < 3; i++)
    System.out.println("A");     // 반복 (3번)
    System.out.println("B");     // 반복 밖! (1번)
// 출력: A A A B
```

### 깨달음
자바는 **들여쓰기를 보지 않는다**. 중괄호가 없으면 바로 다음 **한 문장**만 반복이다.

---

## 4. 반복이 끝난 뒤 변수의 값

### 처음 생각 (오답)
`i < 3`이면 마지막 값이 2니까 반복이 끝나면 `i`는 2라고 생각했다.

### 원리
```java
int i;
for (i = 0; i < 3; i++) { }
System.out.println(i);   // 3
```
```
i=0 → 조건 참 → 본문 → i++
i=1 → 조건 참 → 본문 → i++
i=2 → 조건 참 → 본문 → i++
i=3 → 조건 거짓 → 종료   ← 이때의 i가 남음
```

### 깨달음
반복은 **조건이 거짓이 되는 순간** 끝난다. 그래서 끝난 뒤의 값은 조건을 처음 깨는 값이다.

---

## 5. 중첩 반복의 `break`는 안쪽 반복만 끝낸다

```java
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break;            // 안쪽 for만 종료
        System.out.println(i + "," + j);
    }
}
// 출력: 0,0  1,0
```
바깥 반복은 계속 돈다. `break`는 **자기를 감싼 가장 가까운 반복 하나만** 끝낸다.

---

## 6. `while` + `continue` = 무한 루프 주의

### 처음 생각 (오답)
`continue`는 그냥 이번 바퀴를 건너뛰는 것이니 문제없다고 생각했다.

### 원리
```java
int i = 0;
while (i < 5) {
    if (i == 2) continue;   // i++를 건너뜀 → i는 영원히 2
    i++;
}
```
`for`는 `continue`해도 증가식(`i++`)이 실행되지만, `while`은 증가식이 **본문 안에** 있어서 함께 건너뛰게 된다.

### 깨달음
`while`에서 `continue`를 쓸 때는 **증가식이 continue보다 앞에 있는지** 확인한다.

---

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| else if 참인 것 전부 실행 | 처음 참인 **하나만** |
| 폴스루 = 모든 case | 맞는 case부터 **break까지 아래로** |
| 들여쓰기로 반복 범위 판단 | 중괄호 없으면 **다음 한 문장** |
| 반복 후 i = 2 | 조건을 처음 깨는 값 **3** |
| break가 전부 종료 | **가장 가까운 반복 하나만** |
| while + continue 안전 | 증가식을 건너뛰면 **무한 루프** |
