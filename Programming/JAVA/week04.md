## 1. 절차지향 vs 객체지향
- **절차지향**: 위에서 아래로 하나의 흐름
- **객체지향**: 프로그램을 여러 **객체**로 나누고, 객체들이 서로 상호작용하며 흐름을 만듦

## 2. 객체지향 4대 특징

| 특징 | 뜻 |
|---|---|
| 캡슐화 | 데이터와 메서드를 묶고, 외부에서 함부로 접근 못 하게 숨김 (`private` 등) |
| 상속 | 부모 클래스의 특성을 자식이 물려받음 (자바는 **단일 상속**만) |
| 다형성 | 같은 메서드 호출이 객체에 따라 다르게 동작 (오버라이딩) |
| 추상화 | 세부 구현은 숨기고 핵심 공통 특성만 뽑아냄 (추상 클래스, 인터페이스) |

- 다중 상속 대신 **컴포지션**(생명주기 같음) / **어그리게이션**(생명주기 따로)으로 객체를 조합

## 3. 클래스의 기본 구조
```java
public class Student {
    // 필드 (멤버 변수): 특징
    String name;
    String major;

    // 생성자: new 할 때 실행, 필드 초기화
    Student(String name, String major) {
        this.name = name;
        this.major = major;
    }

    // 메서드: 하는 일
    void study() {
        System.out.println(name + " 공부 중");
    }
}
```
- `.java` 파일 하나에 `public` 클래스는 **1개만**, 그 이름이 **파일 이름**
- 자바에는 전역 변수, 포인터 직접 제어, 다중 상속, 연산자 오버로딩이 없음

## 4. 객체 생성 3가지 방식
```java
class Car {
    String color;

    // 1) 빈 객체를 만들고 나중에 값 채우기
    Car() { }

    // 2), 3) 생성자로 값을 정해서 만들기
    Car(String color) {
        this.color = color;
    }
}

Car c1 = new Car();          // 1) 나중에 c1.color = "빨강";
Car c2 = new Car("파랑");    // 2) 처음부터 값 지정
```
- 3) **생성자 오버로딩**: 기본값 생성자 + 값을 받는 생성자를 같이 두고 필요에 따라 선택

## 5. 생성자 규칙
- 이름이 **클래스 이름과 같고**, 반환형이 **없음**
- `new` 할 때 **자동 실행** (메서드는 호출해야 실행)
- 생성자를 하나도 안 쓰면 컴파일러가 **기본 생성자**를 자동으로 넣음
- `new`의 인자 모양으로 어떤 생성자가 실행될지 결정됨

## 6. this
- `this.필드`: **이 객체의 필드** (매개변수와 이름이 같을 때 구분)
- `this(값)`: **같은 클래스의 다른 생성자** 호출, 생성자 **첫 줄**에만

```java
class Point {
    int x;
    Point(int x) {
        x = x;          // 매개변수에 자기 자신을 대입 → 필드는 0 그대로
    }
}
```
→ `this.x = x;`로 써야 필드에 들어감

## 7. final
- `final` 변수 = 상수. 한 번 값을 넣으면 **수정 불가**

## 8. 객체와 참조 변수
```java
Student s1 = new Student("철수", "컴공");
Student s2 = s1;          // 주소 복사 → 같은 객체
s2.name = "영희";
System.out.println(s1.name);   // 영희
```
- 필드 기본값: `int` 0, `double` 0.0, `boolean` false, 참조형 `null`
- `null`인 변수로 `.`을 찍으면 `NullPointerException`
