## 1. Java와 가장 크게 다른 5가지

| C++ / Java | Python |
|---|---|
| `{ }`로 블록 | **들여쓰기**로 블록, 줄 끝에 `:` |
| `int a = 3;` | `a = 3` (타입 선언·세미콜론 없음) |
| `true` / `false` / `null` | `True` / `False` / `None` (첫 글자 대문자) |
| `&&` `\|\|` `!` | `and` `or` `not` |
| `i++` | 없음 → `i += 1` |

```python
for i in range(3):      # 줄 끝에 콜론
    print("안")         # 들여쓴 줄 = for 안쪽 (3번)
print("밖")             # 들여쓰기 없음 = for 밖 (1번)
```

## 2. print

- 기본으로 **끝에 줄바꿈**을 붙인다 (Java의 `println`)
- 쉼표로 여러 값을 넘기면 사이에 **공백**

| 코드 | 결과 | 설명 |
|---|---|---|
| `print(1, 2)` | `1 2` | 기본 구분자 공백 |
| `print(1, 2, sep="-")` | `1-2` | `sep` = 값 **사이** |
| `print(5, end="/")` | `5/` (줄바꿈 없음) | `end` = **맨 끝**에 붙일 문자 |
| `print("a", end="")` 다음 `print("b")` | `ab` | 두 print가 붙음 |

```python
name, age = "Kim", 20
print(f"{name} {age}")        # Kim 20     (f-string)
print(f"{3.14159:.2f}")       # 3.14
print("%d %s" % (3, "hi"))    # 3 hi
```

- **줄을 바꾸는 건 print의 줄바꿈 문자뿐**. for문이 끝나는 건 출력에 영향 없음
- 서로 다른 print 사이 공백은 앞 print의 `end`가 정한다

```python
for i in range(1, 4):
    print(i, end="/")
print("끝")
# 1/2/3/끝
```

## 3. range(시작, 끝, 간격)

끝 값은 **포함하지 않는다**.

| 코드 | 만들어지는 수 | 반복 횟수 |
|---|---|---|
| `range(4)` | 0, 1, 2, 3 | 4 |
| `range(1, 4)` | 1, 2, 3 | 3 |
| `range(1, 10, 3)` | 1, 4, 7 | 3 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 | 5 (0 미포함) |

```python
for i in range(5, 0, -2):
    print(i, i + 1, sep=",", end="/")
print("끝")
# 5,6/3,4/1,2/끝
```

- 변수를 안 쓰면 `for _ in range(3):`

## 4. 조건문

```python
x = 0
if x > 0:
    print("양수")
elif x == 0:          # else if 아님
    print("0")
else:
    print("음수")
# 0

s = 75
r = "합격" if s >= 60 else "불합격"   # Java의 c ? a : b
print(r)                               # 합격
```

## 5. 연산자

| 연산자 | 예시 | 결과 | Java와 비교 |
|---|---|---|---|
| `/` | `7 / 2` | `3.5` | Java는 `3` |
| `/` | `6 / 2` | `3.0` | **나누어떨어져도 실수** |
| `//` | `7 // 2` | `3` | 몫 (Java의 정수 `/`) |
| `//` | `-7 // 2` | `-4` | 아래로 내림 (Java는 `-3`) |
| `%` | `7 % 2` | `1` | 같음 |
| `**` | `2 ** 3` | `8` | 거듭제곱 |

| 예시 | 결과 | 설명 |
|---|---|---|
| `"ab" * 3` | `ababab` | 문자열 × 정수 = 반복 |
| `"3" + "1"` | `31` | 이어 붙이기 |
| `"3" + 1` | TypeError | Java와 달리 자동 변환 없음 |
| `str(3) + "1"` | `31` | `str()` 숫자 → 문자열 |
| `int("3") + 1` | `4` | `int()` 문자열 → 정수 |
| `True + True` | `2` | True = 1 |
| `1 < 3 < 5` | `True` | 비교를 이어 쓸 수 있음 |

```python
x = 10
x //= 3              # x = x // 3 → 3
y = str(x) * 2       # "3" * 2 → "33"
print(y, x ** 2, x / 1)
# 33 9 3.0
```
