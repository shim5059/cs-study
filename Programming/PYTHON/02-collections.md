## 1. 리스트 인덱싱 · 슬라이싱

```python
a = [10, 20, 30, 40, 50]
```

| 값 | 10 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|
| 앞에서 | 0 | 1 | 2 | 3 | 4 |
| 뒤에서 | -5 | -4 | -3 | -2 | **-1** |

- `a[-1]` → `50` (마지막). Java의 `a[a.length - 1]`
- `a[5]` → IndexError

슬라이싱 `a[시작:끝:간격]`, **끝 미포함** (range와 같은 규칙)

| 코드 | 결과 |
|---|---|
| `a[1:3]` | `[20, 30]` |
| `a[:2]` | `[10, 20]` |
| `a[3:]` | `[40, 50]` |
| `a[-2:]` | `[40, 50]` |
| `a[-3:-1]` | `[30, 40]` |
| `a[::2]` | `[10, 30, 50]` |
| `a[::-1]` | `[50, 40, 30, 20, 10]` (뒤집기) |
| `a[4:1:-1]` | `[50, 40, 30]` (거꾸로, 1번 미포함) |
| `a[1:100]` | `[20, 30, 40, 50]` (넘어도 에러 없음) |

- `a[1]` → `20` (값) / `a[1:2]` → `[20]` (리스트)
- 문자열도 같다: `"PYTHON"[1:4]` → `YTH`, `"PYTHON"[::-1]` → `NOHTYP`

## 2. 리스트 메서드

`a = [3, 1, 2]`에서 차례로

| 코드 | 실행 후 a | 반환값 |
|---|---|---|
| `a.append(4)` | `[3, 1, 2, 4]` | None |
| `a.insert(0, 9)` | `[9, 3, 1, 2, 4]` | None |
| `a.pop()` | `[9, 3, 1, 2]` | **4** |
| `a.pop(0)` | `[3, 1, 2]` | **9** |
| `a.remove(1)` | `[3, 2]` | None |

| | 괄호 안 숫자 | 반환값 |
|---|---|---|
| `pop(1)` | **위치** | 꺼낸 값 |
| `remove(1)` | **값** (앞에서 첫 번째 하나) | None |

| 코드 | 결과 |
|---|---|
| `a.sort()` | a 자체 정렬, 반환 **None** → `print(a.sort())`는 `None` |
| `sorted(a)` | 정렬된 **새 리스트**, a는 그대로 |
| `a.sort(reverse=True)` | 내림차순 |
| `len(a)`, `a.count(x)`, `a.index(x)`, `x in a` | 개수, x 개수, x 위치, 포함 여부 |
| `[1].append([5, 6])` | `[1, [5, 6]]` (통째로 1칸) |
| `[1].extend([5, 6])` | `[1, 5, 6]` (풀어서) |

### `b = a`는 복사가 아니다

```python
a = [1, 2]
b = a          # 같은 리스트를 가리킴
c = a[:]       # 이 시점의 a를 복사한 새 리스트 [1, 2]
b.append(3)    # a, b 둘 다 [1, 2, 3]
c.append(9)    # c만 [1, 2, 9]
print(a, b, c)   # [1, 2, 3] [1, 2, 3] [1, 2, 9]
```
Java에서 배열을 `b = a`로 대입한 것과 같다.

### for는 읽기만, append는 붙이기만

```python
a = [0, 1, 2, 3, 4]
for x in a[:]:              # 복사본을 돌림
    if x % 2 == 0:
        a.append(x * 10)
print(a)                    # [0, 1, 2, 3, 4, 0, 20, 40]

b = [0, 1, 2, 3, 4]
b.append(b.pop(0))          # 맨 앞을 빼서 맨 뒤로 (회전)
print(b)                    # [1, 2, 3, 4, 0]
```
- 원본에서 빠지는 건 `pop`, `remove`뿐
- 돌고 있는 리스트에 직접 append하면 무한 반복이 될 수 있다

## 3. 딕셔너리

```python
d = {'a': 3, 'b': 5}
d['c'] = 7        # 없는 키 → 추가
d['a'] = 10       # 있는 키 → 덮어쓰기
print(d)          # {'a': 10, 'b': 5, 'c': 7}
```

| 코드 | 결과 | 설명 |
|---|---|---|
| `d['z']` | KeyError | 없는 키 |
| `d.get('z')` | `None` | 에러 없음 |
| `d.get('z', 0)` | `0` | 기본값 |
| `len(d)` | `3` | 키 개수 |
| `'c' in d` | `True` | **키만** 검사 |
| `7 in d` | `False` | 7은 값 |
| `7 in d.values()` | `True` | 값 검사 |
| `d.pop('b')` | `5` | 괄호 안은 키 |
| `del d['a']` | | 삭제 |
| `{'x': 1, 'x': 2}` | `{'x': 2}` | 같은 키는 덮어씀 |

| 코드 | 결과 |
|---|---|
| `d.keys()` | 키만 |
| `d.values()` | 값만 |
| `d.items()` | (키, 값) 짝 |

```python
d = {'a': 10, 'b': 5, 'c': 7}
for k in d:                 # 그냥 돌리면 키만
    print(k, end=" ")       # a b c
print()
for k, v in d.items():      # 변수 2개 → items()
    print(k, v, end=" / ")  # a 10 / b 5 / c 7 /
```
- Java로 치면 `in d` = `containsKey`, `in d.values()` = `containsValue`

## 4. 튜플 · 세트

```python
t = (1, 2, 3)
print(t[0], t[-1])     # 1 3
# t[0] = 9             # TypeError: 수정 불가

a, b = 1, 2
a, b = b, a            # 값 교환 (temp 필요 없음)
print(a, b)            # 2 1

s = {3, 1, 3, 2}
print(len(s))          # 3 (중복 제거)
print({1, 2, 3} | {3, 4})       # {1, 2, 3, 4} 합집합
print({1, 2, 3} & {2, 3, 4})    # {2, 3} 교집합
print({1, 2, 3} - {2})          # {1, 3} 차집합
```

## 5. 문자열 메서드

문자열은 **불변**이라 메서드가 원본을 바꾸지 않고 새 값을 돌려준다 (리스트 `sort()`와 반대).

`s = "Hello World"`

| 코드 | 결과 |
|---|---|
| `s.upper()` / `s.lower()` | `HELLO WORLD` / `hello world` |
| `s.split()` | `['Hello', 'World']` |
| `"a,b,,c".split(",")` | `['a', 'b', '', 'c']` |
| `"-".join(['a', 'b', 'c'])` | `a-b-c` (붙일 문자가 앞) |
| `s.replace("o", "0")` | `Hell0 W0rld` |
| `s.find("o")` / `s.find("z")` | `4` / `-1` |
| `s.index("z")` | ValueError |
| `s.count("o")` | `2` |
| `"  hi  ".strip()` | `hi` |
| `s.startswith("He")` | `True` |
| `"123".isdigit()` / `"ab1".isalpha()` | `True` / `False` |

## 6. 리스트 컴프리헨션

```
[ 결과식   for 변수 in 반복대상   if 조건 ]
    ③           ①                  ②
```
맨 앞의 결과식을 **마지막에** 읽는다.

```python
r = []
for x in range(5):
    if x % 2 == 0:
        r.append(x * 10)
print(r)                                       # [0, 20, 40]
print([x * 10 for x in range(5) if x % 2 == 0])   # [0, 20, 40] (위와 같음)

print([x * x for x in range(5)])               # [0, 1, 4, 9, 16]
print([x for x in [3, 8, 1, 6] if x > 2])      # [3, 8, 6]
print([c.upper() for c in "abc"])              # ['A', 'B', 'C']
```

### 예시문제 4번
```python
def test(dict, x):
    return [k for k, v in dict.items() if v == x]

print(test({'a': 1, 'b': 2, 'c': 1}, 1))       # ['a', 'c']
```
키·값 짝을 꺼내서(①) 값이 x와 같으면(②) 키를 담는다(③) = "값이 x인 키를 모두 찾기"

```python
s = "a,b,c,b"
parts = s.split(",")                          # ['a', 'b', 'c', 'b']
r = [p.upper() for p in parts if p != "b"]    # ['A', 'C']
print(len(parts), r, s.count("b"), s.find("c"))
# 4 ['A', 'C'] 2 4     (s는 "a,b,c,b" 그대로)
```
