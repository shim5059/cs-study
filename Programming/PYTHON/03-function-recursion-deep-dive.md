## 1. 재귀 순서를 아예 못 따라갔다

### 처음 생각
```python
def f(n):
    if n <= 0:
        return 0
    print(n, end=" ")
    r = n + f(n - 2)
    print(r, end=" ")
    return r

f(5)
```
"모르겠음, 순서가 어떻게 되는 거임" (정답: `5 3 1 1 4 9`)

### 원리: 규칙 두 개
1. **호출마다 자기 방이 따로 있다**: f(5), f(3), f(1)은 같은 코드지만 각자 n과 r을 따로 가진다. 아파트 5층, 3층, 1층 사람이 각자 메모장을 가진 것과 같다.
2. **함수를 부르면 그 줄에서 멈추고 기다린다**: `r = n + f(n - 2)`에서 덧셈을 바로 하지 않는다. f(n - 2)가 끝나야 덧셈하고 다음 줄로 간다.

| 순서 | 실행 | 출력 |
|---|---|---|
| 1 | f(5): print(5) → `f(3)` 대기 | `5` |
| 2 | f(3): print(3) → `f(1)` 대기 | `5 3` |
| 3 | f(1): print(1) → `f(-1)` 대기 | `5 3 1` |
| 4 | f(-1): 종료 조건, **0 반환 (출력 없음)** | |
| 5 | f(1): r = 1 + 0 = 1, print(1) | `5 3 1 1` |
| 6 | f(3): r = 3 + 1 = 4, print(4) | `5 3 1 1 4` |
| 7 | f(5): r = 5 + 4 = 9, print(9) | `5 3 1 1 4 9` |

### 깨달음
**호출 앞 print는 내려가면서, 호출 뒤 print는 올라오면서** 찍힌다.

## 2. 호출 뒤 print를 거꾸로 썼다

### 처음 생각 (오답)
```python
def g(n):
    if n == 1:
        return 1
    r = g(n - 1) * 2
    print(n, r, end="/")
    return r

print(g(4))
```
내 답: `4 8/3 4/2 2/1 1` (정답: `2 2/3 4/4 8/8`)

계산한 값(2, 4, 8)은 맞았는데 틀린 곳이 세 군데였다.

### 원리
**① 순서가 거꾸로**: g(4)는 print 줄까지 가기 전에 `g(n - 1)`에서 멈춘다. 내려가는 동안은 아무도 print에 도달하지 못한다.

| 구간 | 하는 일 | 출력 |
|---|---|---|
| 내려가기 | g(4) → g(3) → g(2) → g(1), 전부 4번째 줄에서 대기 | 없음 |
| 올라오기 | g(2) → g(3) → g(4) 순서로 print 도달 | `2 2/3 4/4 8/` |

먼저 호출된 함수일수록 가장 늦게 끝난다. 접시를 쌓으면 마지막에 올린 접시를 먼저 꺼내는 것과 같다.

**② `1 1`은 없다**: g(1)은 `return 1`에서 끝나서 print 줄까지 가지 않는다. **종료 조건에 걸린 호출은 그 아래 줄을 실행하지 않는다.**

**③ 마지막 `8`을 빠뜨렸다**: 맨 아래 `print(g(4))`도 print다. g(4)의 **반환값 8**을 출력한다.

## 3. 또 바깥 print를 빠뜨렸다

### 처음 생각 (오답)
```python
def h(n):
    print(n, end="<")
    if n == 0:
        return 10
    v = h(n - 1) + n
    print(v, end=">")
    return v

print(h(2))
```
내 답: `2<1<0<11>13>` (정답: `2<1<0<11>13>13`)

재귀 순서는 완벽했다 (종료 조건 **위**의 print라 `0<`이 찍히는 것까지). 그런데 마지막 13을 또 빠뜨렸다. 함수 안에서 13이 이미 찍혔으니 끝났다고 봤다.

### 원리
`print(h(2))`에는 일이 두 개 들어 있다.

| 순서 | 하는 일 | 화면 |
|---|---|---|
| 1 | h(2) 실행 → 함수 **안의** print들 | `2<1<0<11>13>` |
| 2 | h(2)의 반환값 13을 **바깥** print가 출력 | `13` |

함수 안의 `print(v)`는 **출력**이고 `return v`는 **값을 돌려주는 것**이라 별개다. 택배로 치면 안의 print는 배송 알림 문자, return은 문 앞에 둔 상자, 바깥 print는 상자를 여는 일이다.

### 막혔을 때 풀린 설명: 호출 자리가 반환값으로 바뀐다
```python
print(len("abc"))      # → print(3) → 3
```
```python
def double(x):
    print("계산중", end=" ")
    return x * 2

print(double(4))       # 계산중 8
```
| 단계 | 일어나는 일 | 화면 |
|---|---|---|
| 1 | double(4) 실행, 안의 print | `계산중 ` |
| 2 | 8 반환 → 호출 자리가 바뀜: `print(8)` | |
| 3 | 바깥 print | `계산중 8` |

이미 아는 `len`과 똑같다는 걸 보고 이해됐다.

## 4. `f()`만 쓴 줄도 반환값이 출력된다고 생각했다

### 처음 생각 (오답)
```python
def g(n):
    print(n, end=" ")
    return n * 10

g(1)
x = g(2)
print(g(3), x)
```
내 답: `1 10 2 3 30 20` (정답: `1 2 3 30 20`)

`x = g(2)`가 출력 안 되는 건 맞혔지만 `g(1)` 줄에서 10이 나온다고 봤다.

### 원리
`g(1)` 줄은 함수가 끝나면 그냥 `10`이 된다. 출력하라는 명령(print)도, 저장하라는 명령(=)도 없으니 **버려진다.**

| 줄의 모양 | 반환값 | 화면 |
|---|---|---|
| `g(1)` | 버려짐 | `1 ` |
| `x = g(1)` | x에 저장 | `1 ` |
| `print(g(1))` | 출력 | `1 10` |

대화형 창(`>>>`, 주피터)에서는 `g(1)`만 쳐도 결과가 보이기 때문에 헷갈렸을 수 있다. **시험은 파일 실행 기준**이라 출력되지 않는다.

### 확인 문제 (맞힘)
```python
def p(a):
    print(a * 2, end="/")
    return a + 1

y = p(3)            # 6/   y = 4
p(y)                # 8/   5는 버려짐
print(p(1) + y)     # 2/   print(2 + 4) → 6
# 6/8/2/6
```

## 정리

| 착각 | 바로잡은 규칙 |
|---|---|
| 재귀 순서를 모름 | 호출 줄에서 **멈추고 기다림**, 끝나면 다음 줄 |
| 호출 뒤 print를 위에서부터 | 호출 뒤 print는 **가장 깊은 것부터** |
| 종료 조건 호출도 출력함 | 종료 조건에 걸리면 **아래 줄만** 실행 안 함 (위 줄은 실행) |
| 함수 안에서 찍혔으니 끝 | `print(f())`는 **반환값을 한 번 더** 출력 |
| `f()`만 써도 반환값 출력 | `f()`만 쓰면 반환값은 **버려짐** |

## 5. 또: 올라오며 찍는 값, 바깥 print (2026-11-13)

```python
def f(n):
    if n == 0:
        return 0
    print(n, end=" ")
    r = f(n - 1) + n
    print(r, end=" ")
    return r

print(f(3))
```
내 답: `3 2 1 1 2 3` (정답: `3 2 1 1 3 6 6`)

| 틀린 곳 | 이유 |
|---|---|
| 올라오며 `1 2 3` | 6번 줄은 `print(r)`인데 **n을 찍음** → r = 1, 3, 6 |
| 마지막 6 빠짐 | 맨 아래 `print(f(3))`는 **반환값을 한 번 더** 출력 (3번째 반복) |

> 호출 뒤 print는 **무엇을** 찍는지 줄을 다시 읽는다. 맨 아래 줄이 `print(함수())`면 끝에 반환값이 하나 더 붙는다

## 6. 기본값 매개변수를 그대로 썼다 (2026-11-14)

```python
def greet(name, greeting="안녕"):
    return greeting + ", " + name

print(greet("철수"))
print(greet("영희", "반가워"))
```
내 답 `안녕, 철수 안녕,영희` → 정답은 두 줄 `안녕, 철수` / `반가워, 영희`

- 두 번째 호출은 greeting을 **넘겼으니** 기본값 대신 `반가워`
- `", "`는 쉼표 뒤 공백 한 칸, print가 두 번이라 두 줄
