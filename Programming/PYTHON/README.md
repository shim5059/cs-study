## 실행 결과 문제 체크리스트

틀렸던 것들을 모아 만든 순서다.

1. print마다 `end`가 뭔지 확인 → 줄바꿈 / 공백 / 붙음 결정
2. `/`는 항상 실수, 몫은 `//`
3. `range`·슬라이싱의 끝 값은 미포함
4. 딕셔너리의 `in`은 **키만** 검사
5. 함수 호출 줄의 모양: `f()`만 → 반환값 버림 / `x = f()` → 저장 / `print(f())` → 출력
6. 반환값을 버려도 **메서드가 바꾼 객체 상태는 남음**
7. 재귀: 호출한 줄에서 멈추고, 끝나면 **불렀던 함수의 다음 줄**로 복귀
8. 트리 문제: 트리 그리기 → 함수에서 print 위치·left/right 순서·end 확인 → 묶음으로 쪼개기
